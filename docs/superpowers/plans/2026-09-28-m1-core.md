# M1 — v1 Core (Games, Roster, Waitlist, Notifications, Venues) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the PlayersWanted v1 core: an installable PWA where signed-in players post 5-a-side games, browse them by area, join/leave with an automatic waitlist, and get email/push notifications, all running on Firebase inside free quotas.

**Architecture:** An npm-workspaces monorepo with three packages. `shared/` holds pure TypeScript domain logic (roster rules, validation, formatting) with no Firebase imports. `functions/` holds 2nd-gen Cloud Functions: every write to games and participants goes through a callable function that wraps the `shared/` rules in a Firestore transaction, returns the notifications to send, and sends them after commit. `web/` is a React + Vite PWA that reads Firestore directly through realtime listeners and calls the functions for every game/roster write. Callable logic is written as plain `handler(ctx, input)` functions so integration tests call them directly against the Firestore emulator.

**Tech Stack:** Node 20, TypeScript (strict), npm workspaces, Vitest, React 18 + react-router-dom 6, Vite + vite-plugin-pwa (injectManifest), Firebase JS SDK (Auth, Firestore, Functions, Messaging), firebase-functions v2 API + firebase-admin, esbuild, @firebase/rules-unit-testing, Firebase Emulator Suite, Resend (email over HTTPS), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-27-players-wanted-v1-design.md`. Validation limits and `pitch`-free game shape also follow `docs/superpowers/specs/2026-09-27-players-wanted-match-management-design.md` § CRUD Controls → Game → Validation. Roadmap and open-item decisions: `docs/superpowers/plans/2026-09-28-players-wanted-roadmap.md`.

## Global Constraints

- Node **20** everywhere (`.nvmrc`, `functions/package.json` `engines.node: "20"`, CI).
- TypeScript `strict: true` in every package.
- `shared/` must not import `firebase`, `firebase-admin` or `firebase-functions`. Times in `shared/` are **epoch milliseconds** (`number`).
- Sign-in: **email magic link and Google only**. No passwords, no phone/SMS.
- Clients **read** Firestore directly; **every write to `games` and `participants` goes through a callable Cloud Function**. Security rules deny client writes to those collections.
- Money is **integer pence, GBP** (`costPerPlayerPence`).
- Functions region **`europe-west2`**; create the Firestore database in **`europe-west2`**. Display times in **`Europe/London`**.
- Emulator/test project id: **`demo-playerswanted`** (the `demo-` prefix guarantees no real cloud resources are touched).
- Game validation: `startsAt` between now and **90 days** ahead; `durationMins` **30–180**; `capacity` **6–22 and even**; `costPerPlayerPence` **0–5000**; `notes` ≤ **500** chars; `format` from `["5v5", "6v6", "7v7"]`.
- Error codes: `unauthenticated`, `permission-denied`, `not-found`, `failed-precondition`, `invalid-argument` (plus `internal` for unexpected errors). Server error messages are user-facing sentences.
- Notifications are sent **after** the transaction commits; a notification failure is logged and **never** fails the user's action. Defaults: **email on, push off**.
- Waitlist order: `joinedAt` ascending, then `uid` ascending as a tie-break.
- Organiser is **not** auto-added as a player on `createGame`.
- Push permission is requested only when the PWA is installed **and** after a meaningful action (e.g. joining), never on first load.

## Review Focus

1. **Editing a game after kick-off** (e.g. fixing the venue) with an unchanged `startsAt` must succeed; only a *changed* `startsAt` in the past is rejected. → Task 3 (`validateGameInput` with `existingStartsAt`) and Task 9 (integration).
2. **Moving a game's time** must reset `reminderSentAt`, so the 24h reminder fires for the new time. → Task 9.
3. **Double-tapping Join or retrying after a network blip** must not create a second participant or drift the counts. → Task 4 (`noop`) and Task 10 (integration).
4. **A delayed scheduler run** must not skip a game's reminder. → Task 11 uses a 23h–24h window guarded by `reminderSentAt` (the spec's 23.75–24h window can fall between runs when a run is late). Test in Task 11.
5. **Kick-off times across the BST/GMT change** must display in London time in the UI and in emails, not in the server's UTC. → Task 2 (`formatKickoff` tests on a BST and a GMT date).

Also covered: the sign-in `next` return path must not become an open redirect (Task 14, `safeNext`).

```ts
import type { Game } from './types';

export const APP_TIME_ZONE = 'Europe/London';

export function formatPence(pence: number): string {
  if (pence === 0) return 'Free';
  if (pence % 100 === 0) return `£${pence / 100}`;
  return `£${(pence / 100).toFixed(2)}`;
}

/** Parses "5", "5.50", "£5.50" into pence. Empty input means free (0). Returns null if invalid. */
export function parsePounds(text: string): number | null {
  const cleaned = text.trim().replace(/^£/, '');
  if (cleaned === '') return 0;
  if (!/^\d+(\.\d{1,2})?$/.test(cleaned)) return null;
  const [whole, frac = ''] = cleaned.split('.');
  return Number(whole) * 100 + Number(frac.padEnd(2, '0'));
}

const kickoffFormat = new Intl.DateTimeFormat('en-GB', {
  timeZone: APP_TIME_ZONE,
  weekday: 'short',
  day: 'numeric',
  month: 'short',
  hour: '2-digit',
```

```ts
import { DomainError } from './errors';
import { FORMATS, type Format, type GameInput } from './types';

const DAY_MS = 24 * 60 * 60 * 1000;

export const GAME_LIMITS = {
  maxDaysAhead: 90,
  durationMins: { min: 30, max: 180 },
  capacity: { min: 6, max: 22 },
  costPence: { min: 0, max: 5000 },
  notesMax: 500,
} as const;

export function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === 'object' && v !== null && !Array.isArray(v);
}

function invalid(message: string): never {
  throw new DomainError('invalid-argument', message);
}

function intInRange(value: unknown, min: number, max: number, message: string): number {
  if (typeof value !== 'number' || !Number.isInteger(value) || value < min || value > max) invalid(message);
  return value;
}

export function requireId(raw: unknown, key: string): string {
  const value = isRecord(raw) ? raw[key] : undefined;
  if (typeof value !== 'string' || value.length === 0 || value.length > 128 || value.includes('/')) {
    invalid(`Missing or invalid ${key}.`);
  }
  return value;
}

export function validateGameInput(raw: unknown, now: number, opts: { existingStartsAt?: number } = {}): GameInput {
  if (!isRecord(raw)) invalid('Game details are missing.');
  const venueId = requireId(raw, 'venueId');

  const startsAt = raw.startsAt;
  if (typeof startsAt !== 'number' || !Number.isInteger(startsAt)) invalid('Choose a kick-off date and time.');
  const unchangedStart = opts.existingStartsAt !== undefined && startsAt === opts.existingStartsAt;
  if (!unchangedStart) {
    if (startsAt <= now) invalid('Kick-off must be in the future.');
    if (startsAt > now + GAME_LIMITS.maxDaysAhead * DAY_MS) invalid('Kick-off must be within the next 90 days.');
  }

  const { durationMins: d, capacity: c, costPence: p } = GAME_LIMITS;
  const durationMins = intInRange(raw.durationMins, d.min, d.max, 'Duration must be between 30 and 180 minutes.');
  const capacity = intInRange(raw.capacity, c.min, c.max, 'Capacity must be an even number from 6 to 22.');
  if (capacity % 2 !== 0) invalid('Capacity must be an even number from 6 to 22.');
  const costPerPlayerPence = intInRange(raw.costPerPlayerPence, p.min, p.max, 'Cost per player must be between £0 and £50.');

  if (typeof raw.format !== 'string' || !(FORMATS as readonly string[]).includes(raw.format)) {
    invalid(`Format must be one of ${FORMATS.join(', ')}.`);
  }
  const format = raw.format as Format;

  let notes: string | null = null;
  if (raw.notes !== undefined && raw.notes !== null) {
    if (typeof raw.notes !== 'string') invalid('Notes must be text.');
    const trimmed = raw.notes.trim();
    if (trimmed.length > GAME_LIMITS.notesMax) invalid('Notes must be 500 characters or fewer.');
    notes = trimmed === '' ? null : trimmed;
  }

  return { venueId, startsAt, durationMins, format, capacity, costPerPlayerPence, notes };
}
```

```ts
import { DomainError } from './errors';
import type { Game, Participant } from './types';

export interface Joiner {
  uid: string;
  displayName: string;
}

export interface RosterPlan {
  noop: boolean;
  add: Participant | null;
  removed: Participant | null;
  promoteUids: string[];
  confirmedCount: number;
  waitlistCount: number;
}

export interface JoinOptions {
  allowStarted?: boolean;
}

export function countStates(participants: Participant[]): { confirmed: number; waitlisted: number } {
  let confirmed = 0;
  let waitlisted = 0;
  for (const p of participants) {
    if (p.state === 'confirmed') confirmed++;
    else waitlisted++;
  }
  return { confirmed, waitlisted };
}

export function sortWaitlist(participants: Participant[]): Participant[] {
  return participants
    .filter((p) => p.state === 'waitlisted')
    .sort((a, b) => a.joinedAt - b.joinedAt || a.uid.localeCompare(b.uid));
}

/** Promotes the earliest waitlisted players into any free confirmed places. */
export function fillFromWaitlist(
  participants: Participant[],
  capacity: number,
): Pick<RosterPlan, 'promoteUids' | 'confirmedCount' | 'waitlistCount'> {
  const { confirmed, waitlisted } = countStates(participants);
  const free = Math.max(0, capacity - confirmed);
  const promoteUids = sortWaitlist(participants)
    .slice(0, free)
    .map((p) => p.uid);
  return {
    promoteUids,
    confirmedCount: confirmed + promoteUids.length,
    waitlistCount: waitlisted - promoteUids.length,
  };
}

export function planJoin(
  game: Game,
  participants: Participant[],
  joiner: Joiner,
  now: number,
  opts: JoinOptions = {},
): RosterPlan {
  if (game.status === 'cancelled') throw new DomainError('failed-precondition', 'This game has been cancelled.');
  if (!opts.allowStarted && now >= game.startsAt) {
    throw new DomainError('failed-precondition', 'This game has already started.');
  }

  const { confirmed, waitlisted } = countStates(participants);
  if (participants.some((p) => p.uid === joiner.uid)) {
    return { noop: true, add: null, removed: null, promoteUids: [], confirmedCount: confirmed, waitlistCount: waitlisted };
  }

  const state = confirmed < game.capacity ? 'confirmed' : 'waitlisted';
  const add: Participant = {
    uid: joiner.uid,
    displayName: joiner.displayName,
    gameStartsAt: game.startsAt,
    state,
    joinedAt: now,
    paid: false,
    paidUpdatedAt: null,
  };
  return {
    noop: false,
    add,
    removed: null,
    promoteUids: [],
    confirmedCount: confirmed + (state === 'confirmed' ? 1 : 0),
    waitlistCount: waitlisted + (state === 'waitlisted' ? 1 : 0),
  };
}
```

```ts
export function planLeave(game: Game, participants: Participant[], uid: string): RosterPlan {
  const leaving = participants.find((p) => p.uid === uid);
  if (!leaving) {
    const { confirmed, waitlisted } = countStates(participants);
    return { noop: true, add: null, removed: null, promoteUids: [], confirmedCount: confirmed, waitlistCount: waitlisted };
  }
  const remaining = participants.filter((p) => p.uid !== uid);
  return { noop: false, add: null, removed: leaving, ...fillFromWaitlist(remaining, game.capacity) };
}

export function planCapacityChange(game: Game, participants: Participant[], newCapacity: number): RosterPlan {
  const { confirmed } = countStates(participants);
  if (newCapacity < confirmed) {
    throw new DomainError(
      'failed-precondition',
      `Capacity can't be lower than the ${confirmed} confirmed players. Remove players first.`,
    );
  }
  return {
    noop: newCapacity === game.capacity,
    add: null,
    removed: null,
    ...fillFromWaitlist(participants, newCapacity),
  };
}
```

```ts
import type { NotificationEvent } from '@pw/shared';
import type { Firestore } from 'firebase-admin/firestore';
import { HttpsError, onCall } from 'firebase-functions/v2/https';
import { db } from './admin';
import { REGION, RESEND_API_KEY } from './config';
import { toHttpsError } from './errors';

export interface CallContext {
  uid: string;
  isAdmin: boolean;
  db: Firestore;
  now: number;
}

export interface Notice {
  uid: string;
  event: NotificationEvent;
}

export interface HandlerResult<T> {
  data: T;
  notices: Notice[];
}

export type Handler<T> = (ctx: CallContext, input: unknown) => Promise<HandlerResult<T>>;

type Dispatcher = (notices: Notice[]) => Promise<void>;
let dispatch: Dispatcher = async () => {};

/** Task 8 registers the real dispatcher; kept injectable so this module has no notify import cycle. */
export function setDispatcher(fn: Dispatcher): void {
  dispatch = fn;
}

export function callable<T>(handler: Handler<T>) {
  return onCall({ region: REGION, secrets: [RESEND_API_KEY] }, async (request) => {
    if (!request.auth) throw new HttpsError('unauthenticated', 'Please sign in first.');
    const ctx: CallContext = {
      uid: request.auth.uid,
      isAdmin: request.auth.token.admin === true,
      db,
      now: Date.now(),
    };
    let result: HandlerResult<T>;
    try {
      result = await handler(ctx, request.data);
    } catch (err) {
      throw toHttpsError(err);
    }
    await dispatch(result.notices);
    return result.data;
  });
}
```

```ts
export async function loadGameTx(
  tx: Transaction,
  db: Firestore,
  gameId: string,
): Promise<{ ref: DocumentReference; game: Game; participants: Participant[] }> {
  const ref = db.doc(`games/${gameId}`);
  const snap = await tx.get(ref);
  if (!snap.exists) throw new DomainError('not-found', 'That game no longer exists.');
  const roster = await tx.get(ref.collection('participants'));
  return {
    ref,
    game: gameFromData(snap.id, snap.data()!),
    participants: roster.docs.map((d) => participantFromData(d.data())),
  };
}

export function assertOrganiser(game: Game, uid: string): void {

/** Rejects changes to games that are closed. M4 adds the "completed" branch. */
export function assertOpen(game: Game): void {
  if (game.status === 'cancelled') throw new DomainError('failed-precondition', 'This game has been cancelled.');
}

export function venueSnapshot(d: DocumentData): VenueSnapshot {
  return { name: d.name, address: d.address, areaId: d.areaId, mapsUrl: d.mapsUrl ?? null };
}

export interface ApplyOptions {
  /** Extra fields merged into the single game update. */
  gameFields?: Record<string, unknown>;
  /** Fields written to every participant that stays on the roster. */
  allParticipantFields?: Record<string, unknown>;
}

/** Writes a RosterPlan with at most one write per document. */
export function applyRosterPlan(
  tx: Transaction,
  ref: DocumentReference,
  participants: Participant[],
  plan: RosterPlan,
  now: number,
  opts: ApplyOptions = {},
): void {
  const roster = ref.collection('participants');
  const promote = new Set(plan.promoteUids);
  const all = opts.allParticipantFields ?? {};

  for (const p of participants) {
    if (plan.removed?.uid === p.uid) {
      tx.delete(roster.doc(p.uid));
      continue;
    }
    const fields: Record<string, unknown> = { ...all };
    if (promote.has(p.uid)) fields.state = 'confirmed';
    if (Object.keys(fields).length > 0) tx.update(roster.doc(p.uid), fields);
  }
  if (plan.add) tx.set(roster.doc(plan.add.uid), participantToData(plan.add));

  const gameFields = opts.gameFields ?? {};
  if (plan.noop && Object.keys(gameFields).length === 0) return;
  tx.update(ref, {
    confirmedCount: plan.confirmedCount,
    waitlistCount: plan.waitlistCount,
    updatedAt: ts(now),
    ...gameFields,
  });
}
```

```ts
import type { NotificationEvent } from '@pw/shared';

export interface Message {
  title: string;
  body: string;
  url: string;
}

export function renderNotification(event: NotificationEvent, appUrl: string): Message {
  const url = `${appUrl}/games/${event.gameId}`;
  const label = event.gameLabel;
  switch (event.type) {
    case 'player_joined':
      return {
        title: event.state === 'confirmed' ? `${event.playerName} joined your game` : `${event.playerName} joined the waitlist`,
        body: label,
        url,
      };
    case 'player_left':
      return { title: `${event.playerName} left your game`, body: label, url };
    case 'promoted':
      return { title: "You're in! A space opened up", body: `You've moved off the waitlist for ${label}.`, url };
    case 'removed':
      return { title: 'You were removed from a game', body: `The organiser removed you from ${label}.`, url };
    case 'game_changed':
      return { title: 'Game details changed', body: `${label} — check the new time and venue.`, url };
    case 'game_cancelled':
      return { title: 'Game cancelled', body: `${label} has been cancelled.`, url };
    case 'reminder':
      return { title: 'Game tomorrow', body: `Reminder: you're playing at ${label}.`, url };
    default: {
      const unhandled: never = event;
      throw new Error(`Unhandled notification ${JSON.stringify(unhandled)}`);
    }
  }
}
```

```ts
import { FieldValue, type Firestore } from 'firebase-admin/firestore';
import { getMessaging } from 'firebase-admin/messaging';
import { logger } from 'firebase-functions/v2';
import { APP_URL, EMAIL_FROM, RESEND_API_KEY } from '../lib/config';
import type { Message } from './templates';

export interface Channels {
  email(uid: string, to: string, msg: Message): Promise<void>;
  push(uid: string, token: string, msg: Message): Promise<'ok' | 'invalid-token'>;
}

const INVALID_TOKEN_CODES = new Set([
  'messaging/registration-token-not-registered',
  'messaging/invalid-registration-token',
]);

export const liveChannels: Channels = {
  async email(_uid, to, msg) {
    const res = await fetch('https://api.resend.com/emails', {
      method: 'POST',
      headers: { Authorization: `Bearer ${RESEND_API_KEY.value()}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({
        from: EMAIL_FROM.value(),
        to: [to],
        subject: msg.title,
        text: `${msg.body}\n\nOpen the game: ${msg.url}\n\nChange your notification settings: ${APP_URL.value()}/profile`,
      }),
    });
    if (!res.ok) throw new Error(`Resend responded ${res.status}: ${await res.text()}`);
  },
  async push(_uid, token, msg) {
    try {
      // Data-only message: the service worker renders it (consistent on Android, desktop and iOS PWAs).
      await getMessaging().send({ token, data: { title: msg.title, body: msg.body, url: msg.url } });
      return 'ok';
    } catch (err) {
      const code = (err as { code?: string }).code ?? '';
      if (INVALID_TOKEN_CODES.has(code)) return 'invalid-token';
      throw err;
    }
  },
};

/** Emulator stand-in: logs and records every message in devOutbox so tests and developers can inspect it. */
export function outboxChannels(db: Firestore): Channels {
  return {
    async email(uid, to, msg) {
      logger.info('[email stub]', { to, ...msg });
      await db.collection('devOutbox').add({ channel: 'email', uid, to, ...msg, at: FieldValue.serverTimestamp() });
    },
    async push(uid, token, msg) {
      const invalid = token.startsWith('invalid-');
      logger.info('[push stub]', { token, invalid, ...msg });
      await db
        .collection('devOutbox')
        .add({ channel: 'push', uid, token, invalid, ...msg, at: FieldValue.serverTimestamp() });
      return invalid ? 'invalid-token' : 'ok';
    },
  };
}
```

`functions/src/notify/notify.ts`:
```ts
import type { Firestore } from 'firebase-admin/firestore';
import { logger } from 'firebase-functions/v2';
import { db as defaultDb } from '../lib/admin';
import { setDispatcher, type Notice } from '../lib/callable';
import { APP_URL, isEmulator } from '../lib/config';
import { liveChannels, outboxChannels, type Channels } from './channels';
import { renderNotification } from './templates';

export interface NotifyDeps {
  db: Firestore;
  channels: Channels;
  appUrl: string;
}

function defaultDeps(): NotifyDeps {
  return {
    db: defaultDb,
    channels: isEmulator() ? outboxChannels(defaultDb) : liveChannels,
    appUrl: APP_URL.value(),
  };
}

export async function notify(notice: Notice, deps: NotifyDeps): Promise<void> {
  const userSnap = await deps.db.doc(`users/${notice.uid}`).get();
  if (!userSnap.exists) return;
  const user = userSnap.data()!;
  const wantsEmail = user.notify?.email ?? true;
  const wantsPush = user.notify?.push ?? false;
  const msg = renderNotification(notice.event, deps.appUrl);

  const tasks: Promise<unknown>[] = [];
  if (wantsEmail && typeof user.email === 'string') {
    tasks.push(deps.channels.email(notice.uid, user.email, msg));
  }
  if (wantsPush) {
    const tokens = await deps.db.collection(`users/${notice.uid}/pushTokens`).get();
    for (const tokenDoc of tokens.docs) {
      tasks.push(
        deps.channels.push(notice.uid, tokenDoc.id, msg).then(async (outcome) => {
          if (outcome === 'invalid-token') await tokenDoc.ref.delete();
        }),
      );
    }
  }

  const results = await Promise.allSettled(tasks);
  for (const r of results) {
    if (r.status === 'rejected') {
      logger.error('Notification channel failed', { uid: notice.uid, type: notice.event.type, error: String(r.reason) });
    }
  }
}

export async function dispatchNotices(notices: Notice[], deps: NotifyDeps = defaultDeps()): Promise<void> {
  await Promise.all(
    notices.map((n) =>
      notify(n, deps).catch((err) => logger.error('Notification failed', { uid: n.uid, type: n.event.type, error: String(err) })),
    ),
  );
}

export function installDispatcher(): void {
  setDispatcher((notices) => dispatchNotices(notices));
}
```

```ts
export async function updateGameHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    assertOrganiser(game, ctx.uid);
    assertOpen(game);
    const input = validateGameInput(raw, ctx.now, { existingStartsAt: game.startsAt });

    const venueChanged = input.venueId !== game.venueId;
    let venue = game.venue;
    if (venueChanged) {
      const venueSnap = await tx.get(ctx.db.doc(`venues/${input.venueId}`));
      if (!venueSnap.exists) throw new DomainError('not-found', 'That venue no longer exists.');
      venue = venueSnapshot(venueSnap.data()!);
    }
    const timeChanged = input.startsAt !== game.startsAt;
    const plan = planCapacityChange(game, participants, input.capacity);

    applyRosterPlan(tx, ref, participants, plan, ctx.now, {
      gameFields: {
        venueId: input.venueId,
        venue,
        areaId: venue.areaId,
        startsAt: ts(input.startsAt),
        durationMins: input.durationMins,
        format: input.format,
        capacity: input.capacity,
        costPerPlayerPence: input.costPerPlayerPence,
        notes: input.notes,
        ...(timeChanged ? { reminderSentAt: null } : {}),
      },
      allParticipantFields: timeChanged ? { gameStartsAt: ts(input.startsAt) } : {},
    });

    const label = gameLabel({ venue, startsAt: input.startsAt });
    const notices: Notice[] = [];
    if (timeChanged || venueChanged) {
      for (const p of participants) notices.push({ uid: p.uid, event: { type: 'game_changed', gameId, gameLabel: label } });
    }
    for (const uid of plan.promoteUids) notices.push({ uid, event: { type: 'promoted', gameId, gameLabel: label } });
    return { data: { ok: true as const }, notices };
  });
}
```

```ts
import {
  DomainError,
  gameFromData,
  gameLabel,
  isRecord,
  planJoin,
  planLeave,
  requireId,
  type Game,
  type ParticipantState,
} from '@pw/shared';
import type { Firestore } from 'firebase-admin/firestore';
import type { CallContext, HandlerResult, Notice } from './lib/callable';
import { ts } from './lib/convert';
import { applyRosterPlan, assertOpen, assertOrganiser, loadGameTx } from './lib/games-tx';
import { requireProfile } from './lib/profile';

export async function joinGameHandler(
  ctx: CallContext,
  raw: unknown,
): Promise<HandlerResult<{ state: ParticipantState }>> {
  const gameId = requireId(raw, 'gameId');
  const profile = await requireProfile(ctx.db, ctx.uid);
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    const plan = planJoin(game, participants, { uid: ctx.uid, displayName: profile.displayName }, ctx.now);
    if (plan.noop) {
      const me = participants.find((p) => p.uid === ctx.uid)!;
      return { data: { state: me.state }, notices: [] };
    }
    applyRosterPlan(tx, ref, participants, plan, ctx.now);
    const state = plan.add!.state;
    const notices: Notice[] =
      game.organiserUid === ctx.uid
        ? []
        : [
            {
              uid: game.organiserUid,
              event: { type: 'player_joined', gameId, gameLabel: gameLabel(game), playerName: profile.displayName, state },
            },
          ];
    return { data: { state }, notices };
  });
}

export interface LeaveOptions {
  gameId: string;
  uid: string;
  now: number;
  mode: 'left' | 'removed';
  authorise: (game: Game) => void;
}

/** Removes a player and promotes from the waitlist. Returns the notices to send. */
export async function performLeave(db: Firestore, opts: LeaveOptions): Promise<Notice[]> {
  const { gameId, uid, now, mode } = opts;
  return db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, db, gameId);
    opts.authorise(game);
    assertOpen(game);
    const plan = planLeave(game, participants, uid);
    if (plan.noop) return [];
    applyRosterPlan(tx, ref, participants, plan, now);

    const label = gameLabel(game);
    const notices: Notice[] = [];
    if (mode === 'left' && game.organiserUid !== uid) {
      notices.push({
        uid: game.organiserUid,
        event: { type: 'player_left', gameId, gameLabel: label, playerName: plan.removed!.displayName },
      });
    }
    if (mode === 'removed') notices.push({ uid, event: { type: 'removed', gameId, gameLabel: label } });
    for (const promoted of plan.promoteUids) {
      notices.push({ uid: promoted, event: { type: 'promoted', gameId, gameLabel: label } });
    }
    return notices;
  });
}

export async function leaveGameHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  const notices = await performLeave(ctx.db, { gameId, uid: ctx.uid, now: ctx.now, mode: 'left', authorise: () => {} });
  return { data: { ok: true }, notices };
}

export async function removePlayerHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  const uid = requireId(raw, 'uid');
  const notices = await performLeave(ctx.db, {
    gameId,
    uid,
    now: ctx.now,
    mode: 'removed',
    authorise: (game) => assertOrganiser(game, ctx.uid),
  });
  return { data: { ok: true }, notices };
}

export async function setPaidHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  const uid = requireId(raw, 'uid');
  const paid = isRecord(raw) ? raw.paid : undefined;
  if (typeof paid !== 'boolean') throw new DomainError('invalid-argument', 'paid must be true or false.');

  await ctx.db.runTransaction(async (tx) => {
    const gameRef = ctx.db.doc(`games/${gameId}`);
    const gameSnap = await tx.get(gameRef);
    if (!gameSnap.exists) throw new DomainError('not-found', 'That game no longer exists.');
    assertOrganiser(gameFromData(gameSnap.id, gameSnap.data()!), ctx.uid);
    const pRef = gameRef.collection('participants').doc(uid);
    const pSnap = await tx.get(pRef);
    if (!pSnap.exists) throw new DomainError('not-found', 'That player is not on this game.');
    if (pSnap.data()!.state !== 'confirmed') {
      throw new DomainError('failed-precondition', 'Only confirmed players can be marked as paid.');
    }
    tx.update(pRef, { paid, paidUpdatedAt: ts(ctx.now) });
  });
  return { data: { ok: true }, notices: [] };
}
```

```ts
import { gameFromData, gameLabel } from '@pw/shared';
import type { Firestore } from 'firebase-admin/firestore';
import type { Notice } from './lib/callable';
import { ts } from './lib/convert';

const HOUR = 3_600_000;
export const REMINDER_WINDOW = { fromMs: 23 * HOUR, toMs: 24 * HOUR };

export async function runReminders(db: Firestore, now: number): Promise<Notice[]> {
  const candidates = await db
    .collection('games')
    .where('status', '==', 'scheduled')
    .where('startsAt', '>=', ts(now + REMINDER_WINDOW.fromMs))
    .where('startsAt', '<=', ts(now + REMINDER_WINDOW.toMs))
    .get();

  const notices: Notice[] = [];
  for (const candidate of candidates.docs) {
    const claimed = await db.runTransaction(async (tx) => {
      const fresh = await tx.get(candidate.ref);
      const game = gameFromData(fresh.id, fresh.data()!);
      if (game.status !== 'scheduled' || game.reminderSentAt !== null) return null;
      const confirmed = await tx.get(candidate.ref.collection('participants').where('state', '==', 'confirmed'));
      tx.update(candidate.ref, { reminderSentAt: ts(now) });
      return { game, uids: confirmed.docs.map((d) => d.id) };
    });
    if (!claimed) continue;
    const label = gameLabel(claimed.game);
    for (const uid of claimed.uids) {
      notices.push({ uid, event: { type: 'reminder', gameId: claimed.game.id, gameLabel: label } });
    }
  }
  return notices;
}
```

```ts
/**
 * Emulator:    npm run seed
 * Production:  npm run seed -- --areas-only --project <project-id>   (needs `gcloud auth application-default login`)

import { readFileSync } from 'node:fs';
import { initializeApp } from 'firebase-admin/app';
import { getAuth } from 'firebase-admin/auth';
import { getFirestore, Timestamp } from 'firebase-admin/firestore';

const args = process.argv.slice(2);
const projectFlag = args.indexOf('--project');
const projectId = projectFlag >= 0 ? args[projectFlag + 1] : 'demo-playerswanted';
const areasOnly = args.includes('--areas-only');
const isDemo = projectId.startsWith('demo-');

if (!isDemo && !areasOnly) {
  console.error('Refusing to seed sample users/games into a real project. Use --areas-only.');
  process.exit(1);
}
if (isDemo) {
  process.env.FIRESTORE_EMULATOR_HOST ??= '127.0.0.1:8080';
  process.env.FIREBASE_AUTH_EMULATOR_HOST ??= '127.0.0.1:9099';
}

initializeApp({ projectId });
const db = getFirestore();
const now = Date.now();
const HOUR = 3_600_000;

const areas: { id: string; name: string; order: number }[] = JSON.parse(
  readFileSync(new URL('./areas.json', import.meta.url), 'utf8'),
);

async function main() {
  for (const a of areas) await db.doc(`areas/${a.id}`).set({ name: a.name, order: a.order });
  console.log(`Seeded ${areas.length} areas into ${projectId}`);
  if (areasOnly) return;

  const home = areas[0].id;
  const venues = [
    { id: 'leisure-centre', name: 'Leisure Centre', address: '1 High St' },
    { id: 'astro-park', name: 'Astro Park', address: '2 Park Rd' },
  ];
  for (const v of venues) {
    await db.doc(`venues/${v.id}`).set({
      name: v.name,
      address: v.address,
      areaId: home,
      createdBy: 'seed',
      createdAt: Timestamp.now(),
    });
  }

  const auth = getAuth();
  const users = ['Olly Organiser', 'Alice', 'Bob', 'Carol', 'Dan', 'Erin'];
  const uids: string[] = [];
  for (const name of users) {
    const email = `${name.split(' ')[0].toLowerCase()}@example.com`;
    const user = await auth.getUserByEmail(email).catch(() => auth.createUser({ email, displayName: name }));
    uids.push(user.uid);
    await db.doc(`users/${user.uid}`).set({
      displayName: name,
      email,
      photoURL: null,
      homeAreaId: home,
      notify: { email: true, push: false },
      createdAt: Timestamp.now(),
    });
  }

  const [organiser, ...players] = uids;
  const gameRef = db.collection('games').doc('seed-game');
  const startsAt = Timestamp.fromMillis(now + 26 * HOUR);
  await gameRef.set({
    organiserUid: organiser,
    organiserName: users[0],
    venueId: venues[0].id,
    venue: { name: venues[0].name, address: venues[0].address, areaId: home, mapsUrl: null },
    areaId: home,
    startsAt,
    durationMins: 60,
    format: '5v5',
    capacity: 10,
    costPerPlayerPence: 500,
    notes: 'Seeded game',
    status: 'scheduled',
    confirmedCount: players.length,
    waitlistCount: 0,
    reminderSentAt: null,
    createdAt: Timestamp.now(),
    updatedAt: Timestamp.now(),
  });
  for (const [i, uid] of players.entries()) {
    await gameRef.collection('participants').doc(uid).set({
      uid,
      displayName: users[i + 1],
      gameStartsAt: startsAt,
      state: 'confirmed',
      joinedAt: Timestamp.fromMillis(now + i),
      paid: false,
      paidUpdatedAt: null,
    });
  }
  console.log('Seeded venues, users and one game. Sign in at the Auth emulator with e.g. alice@example.com.');
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

```ts
const OFFLINE = "You're offline — try again when you're connected.";

const MESSAGES: Record<string, string> = {
  'functions/unauthenticated': 'Please sign in first.',
  'functions/permission-denied': 'Only the organiser can do that.',
  'functions/unavailable': OFFLINE,
  'functions/deadline-exceeded': OFFLINE,
  'functions/internal': 'Something went wrong on our side. Please try again.',
  'auth/popup-closed-by-user': 'Sign-in was cancelled.',
  'auth/invalid-action-code': 'This sign-in link has expired or was already used. Request a new one.',
  'auth/invalid-email': 'Enter a valid email address.',
  'auth/network-request-failed': OFFLINE,
  'permission-denied': "You don't have permission to do that.",
  unavailable: OFFLINE,
};

const SHOW_SERVER_MESSAGE = new Set(['functions/failed-precondition', 'functions/invalid-argument', 'functions/not-found']);

export function errorMessage(err: unknown): string {
  const code = typeof err === 'object' && err !== null && 'code' in err ? String((err as { code: unknown }).code) : '';
  const message = err instanceof Error ? err.message : '';
  if (SHOW_SERVER_MESSAGE.has(code) && message) return message;
  return MESSAGES[code] ?? 'Something went wrong. Please try again.';
}
```

```ts
import { useEffect, useState } from 'react';

export function useOnline(): boolean {
  const [online, setOnline] = useState(() => navigator.onLine);
  useEffect(() => {
    const up = () => setOnline(true);
    const down = () => setOnline(false);
    window.addEventListener('online', up);
    window.addEventListener('offline', down);
    return () => {
      window.removeEventListener('online', up);
      window.removeEventListener('offline', down);
    };
  }, []);
  return online;
}
```

```ts
import type { GameInput, ParticipantState } from '@pw/shared';
import { httpsCallable } from 'firebase/functions';

function call<I, O>(name: string) {
  const fn = httpsCallable<I, O>(functions, name);
  return async (input: I): Promise<O> => (await fn(input)).data;
}

type GameRef = { gameId: string };

export const api = {
```

```ts
/** Only allow same-origin, in-app return paths after sign-in. */
export function safeNext(next: string | null): string {
  if (!next || !next.startsWith('/') || next.startsWith('//') || next.startsWith('/\\')) return '/';
  if (next.startsWith('/sign-in') || next.startsWith('/finish-sign-in')) return '/';
  return next;
}
```

```ts
import type { Area } from '@pw/shared';
import {
  collection,
  doc,
  onSnapshot,
  orderBy,
  query,
  type DocumentSnapshot,
  type Query,
  type QueryDocumentSnapshot,
} from 'firebase/firestore';
import { useEffect, useState, type DependencyList } from 'react';
import { db } from '../firebase';

export interface Live<T> {
  data: T;
  loading: boolean;
  error: Error | null;
}

export function useLiveQuery<T>(
  make: () => Query | null,
  map: (d: QueryDocumentSnapshot) => T,
  deps: DependencyList,
): Live<T[]> {
  const [state, setState] = useState<Live<T[]>>({ data: [], loading: true, error: null });
  useEffect(() => {
    const q = make();
    if (!q) {
      setState({ data: [], loading: false, error: null });
      return;
    }
    setState((s) => ({ ...s, loading: true }));
    return onSnapshot(
      q,
      (snap) => setState({ data: snap.docs.map(map), loading: false, error: null }),
      (error) => setState({ data: [], loading: false, error }),
    );
  }, deps);
  return state;
}

export function useLiveDoc<T>(path: string | null, map: (d: DocumentSnapshot) => T | null): Live<T | null> {
  const [state, setState] = useState<Live<T | null>>({ data: null, loading: true, error: null });
  useEffect(() => {
    if (!path) {
      setState({ data: null, loading: false, error: null });
      return;
    }
    setState((s) => ({ ...s, loading: true }));
    return onSnapshot(
      doc(db, path),
      (snap) => setState({ data: map(snap), loading: false, error: null }),
      (error) => setState({ data: null, loading: false, error }),
    );
  }, [path]);
  return state;
}

export function useAreas(): Live<Area[]> {
  return useLiveQuery(
    () => query(collection(db, 'areas'), orderBy('order')),
    (d) => ({ id: d.id, name: d.data().name as string, order: d.data().order as number }),
    [],
  );
}
```

```tsx
import { profileFromData, type UserProfile } from '@pw/shared';
import { onAuthStateChanged, type User } from 'firebase/auth';
import { doc, onSnapshot } from 'firebase/firestore';
import { createContext, useContext, useEffect, useState, type ReactNode } from 'react';
import { auth, db } from '../firebase';

interface AuthState {
  user: User | null;
  profile: UserProfile | null;
  loading: boolean;
}

const AuthContext = createContext<AuthState>({ user: null, profile: null, loading: true });

export function AuthProvider({ children }: { children: ReactNode }) {
  const [state, setState] = useState<AuthState>({ user: null, profile: null, loading: true });

  useEffect(() => {
    let stopProfile: (() => void) | undefined;
    const stopAuth = onAuthStateChanged(auth, (user) => {
      stopProfile?.();
      stopProfile = undefined;
      if (!user) {
        setState({ user: null, profile: null, loading: false });
        return;
      }
      setState({ user, profile: null, loading: true });
      stopProfile = onSnapshot(
        doc(db, 'users', user.uid),
        (snap) => setState({ user, profile: snap.exists() ? profileFromData(snap.data()) : null, loading: false }),
        () => setState({ user, profile: null, loading: false }),
      );
    });
    return () => {
      stopProfile?.();
      stopAuth();
    };
  }, []);

  return <AuthContext.Provider value={state}>{children}</AuthContext.Provider>;
}

export function useAuth(): AuthState {
  return useContext(AuthContext);
}
```

```tsx
    } catch (err) {
      setError(errorMessage(err));

      setError(errorMessage(err));
    }

      <h1>Sign in</h1>

          </p>
```

```tsx
import { isSignInWithEmailLink, signInWithEmailLink } from 'firebase/auth';
import { useEffect, useRef, useState, type FormEvent } from 'react';
import { useNavigate, useSearchParams } from 'react-router-dom';
import { auth } from '../firebase';
import { errorMessage } from '../lib/errors';
import { safeNext } from '../lib/safeNext';
import { EMAIL_KEY } from './SignIn';

type Phase = 'working' | 'need-email' | 'invalid';

function storedEmail(): string | null {
  try {
    return localStorage.getItem(EMAIL_KEY);
  } catch {
    return null;
  }
}

export function FinishSignIn() {
  const [params] = useSearchParams();
  const next = safeNext(params.get('next'));
  const navigate = useNavigate();
  const [phase, setPhase] = useState<Phase>('working');
  const [email, setEmail] = useState('');
  const [error, setError] = useState<string | null>(null);
  const started = useRef(false);

  async function complete(address: string) {
    setPhase('working');
    try {
      await signInWithEmailLink(auth, address, window.location.href);
      try {
        localStorage.removeItem(EMAIL_KEY);
      } catch {
        // ignore
      }
      navigate(next, { replace: true });
    } catch (err) {
      setError(errorMessage(err));
      setPhase('need-email');
    }
  }

  useEffect(() => {
    if (started.current) return; // StrictMode runs effects twice; a link can only be used once.
    started.current = true;
    if (!isSignInWithEmailLink(auth, window.location.href)) {
      setPhase('invalid');
      return;
    }
    const saved = storedEmail();
    if (saved) void complete(saved);
    else setPhase('need-email');
  }, []);

  if (phase === 'invalid') return <p>This sign-in link isn't valid. Go back and request a new one.</p>;
  if (phase === 'working') return <p className="muted">Signing you in…</p>;
  return (
    <form
      onSubmit={(e: FormEvent) => {
        e.preventDefault();
        void complete(email.trim());
      }}
    >
      <h1>Confirm your email</h1>
      <p className="muted">You opened the link on a different device or browser. Enter the email you used.</p>
      <label htmlFor="email">Email</label>
      <input id="email" type="email" required value={email} onChange={(e) => setEmail(e.target.value)} />
      <p>
        <button type="submit">Sign in</button>
      </p>
      {error && <p className="error">{error}</p>}
    </form>
  );
}
```

```tsx
import { doc, serverTimestamp, setDoc } from 'firebase/firestore';
import { useState, type FormEvent } from 'react';
import { AreaSelect } from '../components/AreaSelect';
import { db } from '../firebase';
import { errorMessage } from '../lib/errors';
import { useAreas } from '../lib/hooks';
import { useAuth } from './AuthProvider';

export function Onboarding() {
  const { user } = useAuth();
  const areas = useAreas();
  const [name, setName] = useState(user?.displayName ?? '');
  const [areaId, setAreaId] = useState('');
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const selectedArea = areaId || areas.data[0]?.id || '';

  async function save(e: FormEvent) {
    e.preventDefault();
    if (!user) return;
    const displayName = name.trim();
    if (displayName.length < 2 || displayName.length > 30) {
      setError('Your name must be 2–30 characters.');
      return;
    }
    setBusy(true);
    setError(null);
    try {
      await setDoc(doc(db, 'users', user.uid), {
        displayName,
        email: user.email,
        photoURL: user.photoURL ?? null,
        homeAreaId: selectedArea,
        notify: { email: true, push: false },
        createdAt: serverTimestamp(),
      });
    } catch (err) {
      setError(errorMessage(err));
    } finally {
      setBusy(false);
    }
  }

  return (
    <form onSubmit={save}>
      <h1>Welcome to PlayersWanted</h1>
      <label htmlFor="name">Your name (shown to other players)</label>
      <input id="name" value={name} maxLength={30} onChange={(e) => setName(e.target.value)} />
      <label htmlFor="area">Home area</label>
      <AreaSelect id="area" value={selectedArea} areas={areas.data} onChange={setAreaId} />

        <button type="submit" disabled={busy || !selectedArea}>
          Continue
        </button>
      </p>
      {error && <p className="error">{error}</p>}

  );
}
```

```ts
import { hasStarted, isFull, type Game, type Participant } from '@pw/shared';

export type PrimaryAction =
  | { kind: 'sign-in' | 'join' | 'join-waitlist' | 'leave' | 'leave-waitlist'; label: string }
  | { kind: 'none'; label: string };

export function primaryAction(game: Game, me: Participant | undefined, signedIn: boolean, now: number): PrimaryAction {
  if (game.status === 'cancelled') return { kind: 'none', label: 'This game was cancelled' };
  if (me) return me.state === 'confirmed' ? { kind: 'leave', label: 'Leave game' } : { kind: 'leave-waitlist', label: 'Leave waitlist' };
  if (hasStarted(game, now)) return { kind: 'none', label: 'This game has started' };
  if (!signedIn) return { kind: 'sign-in', label: 'Sign in to join' };
```

```ts
const pad = (n: number) => String(n).padStart(2, '0');

/** Epoch ms → value for <input type="datetime-local"> in the device's timezone. */
export function toLocalInput(ms: number): string {
  const d = new Date(ms);
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}T${pad(d.getHours())}:${pad(d.getMinutes())}`;
}

export function fromLocalInput(value: string): number | null {
  if (!value) return null;
  const ms = new Date(value).getTime();
  return Number.isNaN(ms) ? null : ms;
}
```

```ts
import { doc, serverTimestamp, setDoc, updateDoc } from 'firebase/firestore';
import { getMessaging, getToken, isSupported } from 'firebase/messaging';
import { app, db } from './firebase';

type Permission = NotificationPermission | 'unsupported';

export function isStandalone(): boolean {
  return (
    window.matchMedia('(display-mode: standalone)').matches ||
    (navigator as Navigator & { standalone?: boolean }).standalone === true
  );
}

export function currentPermission(): Permission {
  return 'Notification' in window ? Notification.permission : 'unsupported';
}

export function shouldPromptForPush(env: { standalone: boolean; permission: Permission; pushOn: boolean }): boolean {
  return env.standalone && env.permission === 'default' && !env.pushOn;
}

export async function enablePush(uid: string): Promise<'enabled' | 'denied' | 'unsupported'> {
  if (!('Notification' in window) || !('serviceWorker' in navigator) || !(await isSupported())) return 'unsupported';
  const permission = await Notification.requestPermission();
  if (permission !== 'granted') return 'denied';
  const registration = await navigator.serviceWorker.ready;
  const token = await getToken(getMessaging(app), {
    vapidKey: import.meta.env.VITE_FIREBASE_VAPID_KEY,
    serviceWorkerRegistration: registration,
  });
  await setDoc(doc(db, 'users', uid, 'pushTokens', token), {
    createdAt: serverTimestamp(),
    userAgent: navigator.userAgent.slice(0, 300),
  });
  await updateDoc(doc(db, 'users', uid), { 'notify.push': true });
  return 'enabled';
}

export async function disablePush(uid: string): Promise<void> {
  await updateDoc(doc(db, 'users', uid), { 'notify.push': false });
}
```

```tsx
export function Profile() {
  const { user, profile } = useAuth();
  const areas = useAreas();
  const navigate = useNavigate();
  const [name, setName] = useState(profile?.displayName ?? '');
  const [areaId, setAreaId] = useState(profile?.homeAreaId ?? '');
  const [message, setMessage] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);

  const uid = user.uid;

    setError(null);
    setMessage(null);

      await fn();
      setMessage(success);
    } catch (err) {
      setError(errorMessage(err));
    }

    const displayName = name.trim();

    void run(() => updateDoc(doc(db, 'users', uid), { displayName, homeAreaId: areaId }), 'Saved.');

      return null;

    if (outcome === 'unsupported') setError('This browser does not support push notifications.');

          <button type="submit">Save</button>
        </p>

        <input

          checked={profile.notify.email}

            void run(() => updateDoc(doc(db, 'users', uid), { 'notify.email': e.target.checked }), 'Saved.')
```

```markdown
# Deployment runbook

One-time setup for a new Firebase project.

1. Create a Firebase project and upgrade it to the **Blaze** plan. In Google Cloud Billing, add a **$5 budget alert**.
2. Create the Firestore database in **europe-west2** (London).
3. Authentication → Sign-in method: enable **Email link (passwordless)** and **Google**. Add the Hosting domain to Authorised domains.
4. Project settings → Cloud Messaging → Web Push certificates: generate a key pair. This is `VITE_FIREBASE_VAPID_KEY`.
5. Project settings → Your apps: add a Web app. Copy its config into the GitHub repository **variables** `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_STORAGE_BUCKET`, `VITE_FIREBASE_MESSAGING_SENDER_ID`, `VITE_FIREBASE_APP_ID`, plus `FIREBASE_PROJECT_ID`, `APP_URL` (e.g. `https://<project>.web.app`) and `EMAIL_FROM` (e.g. `PlayersWanted <games@yourdomain>`).
6. Resend: verify the sending domain, create an API key, then run `npx firebase functions:secrets:set RESEND_API_KEY --project <project>`.
7. Create a service account with the **Firebase Admin** and **Cloud Functions Admin**, **Service Account User**, **Secret Manager Secret Accessor** roles. Store its JSON key as the GitHub **secret** `FIREBASE_SERVICE_ACCOUNT`, and create a GitHub environment named `production`.
8. Seed the real areas: edit `scripts/areas.json`, then `npm run seed -- --areas-only --project <project>` (needs `gcloud auth application-default login`).
9. Push to `main`. The `deploy` job runs `firebase deploy` (hosting, functions, rules, indexes).
```
