# M2 — Players & Game Controls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add public player profiles (avatar, preferred position, stats placeholders), the pitch field, an organiser audit log, and the new game controls `addPlayer`, `deleteGame` and self-serve `deleteAccount`, plus the opt-in "new game in my area" notification.

**Architecture:** A Firestore trigger (`onUserWrite`) mirrors the public fields of the owner-only `users/{uid}` doc into a functions-only `players/{uid}` doc that other signed-in users can read. New callables follow the M1 pattern: a `handler(ctx, input)` that runs a transaction, returns notices, and is wrapped by `callable()`. Account deletion anonymises the player rather than deleting it, so past games and later results stay intact.

**Tech Stack:** As M1, plus Cloud Storage for Firebase (avatars) and `firebase-functions/v2/firestore` triggers.

**Spec:** `docs/superpowers/specs/2026-09-27-players-wanted-match-management-design.md` (sections Roles, Data Model Changes, CRUD Controls → Game and Player, Notifications, Screens 3/5/6, milestone M2). Builds on `docs/superpowers/plans/2026-09-28-m1-core.md`.

**Prerequisite:** M1 merged. All M1 names (`CallContext`, `Notice`, `callable`, `loadGameTx`, `assertOrganiser`, `assertOpen`, `applyRosterPlan`, `performLeave`, `cancelGameTx`, `planJoin`, test helpers) are used as defined there.

## Global Constraints

Everything in the M1 Global Constraints, plus:

- `players/{uid}`, `games/{id}/audit/*` are **functions-only** writes. `players` is readable by **signed-in users only**. `audit` is readable by the **game's organiser and admins** only.
- New players start at `rating: 1200` with zeroed stats; stats are never writable through the profile.
- `displayName` 2–30 chars, trimmed. `preferredPosition` ∈ `GK | DEF | MID | FWD | ANY`. `pitch` ≤ 10 chars.
- Avatars live at `avatars/{uid}.jpg`, owner-write only, images only, ≤ 1 MB, resized client-side to 256×256.
- Renames do **not** rewrite old snapshots on games and participants.
- `deleteGame`: only when the game has **no participants other than the organiser** and has **never had a result**; admins may delete any game that has no final result.
- `deleteAccount` **anonymises** (`displayName: "Former player"`, `status: "deleted"`, photo removed) and deletes `users/{uid}`, push tokens, the avatar and the Auth user. It cancels upcoming organised games and leaves upcoming joined games.
- `newGamesInArea` notification defaults **off** and fires only when `startsAt` is **≥ 2h** away.
- Admin = Firebase custom claim `admin: true`.

## Review Focus

1. **A player added by the organiser after kick-off into a full game** goes to the waitlist, not over capacity. → Task 5 test.
2. **Deleting an account while the user sits on another game's waitlist or roster** must promote the next player and tell the organiser. → Task 7 test.
3. **An old `onUserWrite` event arriving after deletion** must not resurrect the player's name. → Task 3 test (`syncPlayerFromUser` ignores `status: "deleted"`).
4. **Double-tapping Delete game while a player joins** must not delete a game someone just joined. → Task 6 does the check and delete in one transaction; test covers "joined → refused".
5. **Account deletion leaves the real name on past rosters** (spec silence). The plan also rewrites the deleted user's participant and organiser name snapshots to "Former player". This is a deliberate extension, listed in the roadmap for confirmation. → Task 7 test.

```ts
import { DomainError } from './errors';
import type { Game, Participant } from './types';

export const POSITIONS = ['GK', 'DEF', 'MID', 'FWD', 'ANY'] as const;
export type Position = (typeof POSITIONS)[number];

export const BASE_RATING = 1200;
export const CALIBRATION_GAMES = 3;
export const DELETED_PLAYER_NAME = 'Former player';

export interface PlayerStats {
  rating: number;
  ratedGames: number;
  wins: number;
  draws: number;
  losses: number;
  goals: number;
  gamesPlayed: number;
  noShows: number;
}

export const INITIAL_STATS: PlayerStats = {
  rating: BASE_RATING,
  ratedGames: 0,
  wins: 0,
  draws: 0,
  losses: 0,
  goals: 0,
  gamesPlayed: 0,
  noShows: 0,
};

export interface PublicProfile {
  displayName: string;
  displayNameLower: string;
  photoURL: string | null;
  preferredPosition: Position | null;
  homeAreaId: string;
}

export type PlayerStatus = 'active' | 'deleted';

export interface Player extends PublicProfile, PlayerStats {
  uid: string;
  status: PlayerStatus;
  lastResultAt: number | null;
  createdAt: number;
  updatedAt: number;
}

export function isPosition(v: unknown): v is Position {
  return typeof v === 'string' && (POSITIONS as readonly string[]).includes(v);
}

export function normaliseDisplayName(raw: unknown): string {
  if (typeof raw !== 'string') throw new DomainError('invalid-argument', 'Enter a name.');
  const name = raw.trim().replace(/\s+/g, ' ');
  if (name.length < 2 || name.length > 30) throw new DomainError('invalid-argument', 'Your name must be 2–30 characters.');
  return name;
}

export function publicProfileFromUser(user: Record<string, unknown>): PublicProfile {
  const displayName = String(user.displayName ?? '').trim();
  return {
    displayName,
    displayNameLower: displayName.toLowerCase(),
    photoURL: typeof user.photoURL === 'string' ? user.photoURL : null,
    preferredPosition: isPosition(user.preferredPosition) ? user.preferredPosition : null,
    homeAreaId: String(user.homeAreaId ?? ''),
  };
}

export function publicProfileChanged(existing: Record<string, unknown>, next: PublicProfile): boolean {
  return (Object.keys(next) as (keyof PublicProfile)[]).some((k) => (existing[k] ?? null) !== next[k]);
}

const num = (v: unknown, fallback: number) => (typeof v === 'number' ? v : fallback);
const ms = (v: unknown): number | null =>
  v && typeof v === 'object' && 'toMillis' in v ? (v as { toMillis(): number }).toMillis() : typeof v === 'number' ? v : null;

export function playerFromData(uid: string, d: Record<string, unknown>): Player {
  return {
    uid,
    ...publicProfileFromUser(d),
    status: d.status === 'deleted' ? 'deleted' : 'active',
    rating: num(d.rating, INITIAL_STATS.rating),
    ratedGames: num(d.ratedGames, 0),
    wins: num(d.wins, 0),
    draws: num(d.draws, 0),
    losses: num(d.losses, 0),
    goals: num(d.goals, 0),
    gamesPlayed: num(d.gamesPlayed, 0),
    noShows: num(d.noShows, 0),
    lastResultAt: ms(d.lastResultAt),
    createdAt: ms(d.createdAt) ?? 0,
    updatedAt: ms(d.updatedAt) ?? 0,
  };
}

export function isCalibrated(p: Pick<PlayerStats, 'ratedGames'>): boolean {
  return p.ratedGames >= CALIBRATION_GAMES;
}

export function ratingLabel(p: Pick<PlayerStats, 'ratedGames' | 'rating'>): string {
  return isCalibrated(p) ? String(p.rating) : `Calibrating (${Math.min(p.ratedGames, CALIBRATION_GAMES)}/${CALIBRATION_GAMES})`;
}

/** UI-side check; the server also refuses when a result exists. */
export function canDeleteGame(game: Game, participants: Participant[]): boolean {
  return participants.every((p) => p.uid === game.organiserUid);
}
```

```ts
import { INITIAL_STATS, publicProfileChanged, publicProfileFromUser } from '@pw/shared';
import type { Firestore } from 'firebase-admin/firestore';
import { ts } from './lib/convert';

export async function syncPlayerFromUser(
  db: Firestore,
  uid: string,
  user: Record<string, unknown> | null,
  now: number,
): Promise<void> {
  if (!user) return; // deleteAccount handles anonymisation.
  const ref = db.doc(`players/${uid}`);
  const profile = publicProfileFromUser(user);
  await db.runTransaction(async (tx) => {
    const snap = await tx.get(ref);
    if (!snap.exists) {
      tx.set(ref, {
        ...profile,
        ...INITIAL_STATS,
        status: 'active',
        lastResultAt: null,
        createdAt: ts(now),
        updatedAt: ts(now),
      });
      return;
    }
    const existing = snap.data()!;
    if (existing.status === 'deleted') return;
    if (!publicProfileChanged(existing, profile)) return;
    tx.update(ref, { ...profile, updatedAt: ts(now) });
  });
}
```

```ts
export async function addPlayerHandler(
  ctx: CallContext,
  raw: unknown,
): Promise<HandlerResult<{ state: ParticipantState }>> {
  const gameId = requireId(raw, 'gameId');
  const uid = requireId(raw, 'uid');
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    assertOrganiser(game, ctx.uid);
    const playerSnap = await tx.get(ctx.db.doc(`players/${uid}`));
    if (!playerSnap.exists || playerSnap.data()!.status !== 'active') {
      throw new DomainError('failed-precondition', "That player can't be added.");
    }
    const plan = planJoin(game, participants, { uid, displayName: playerSnap.data()!.displayName }, ctx.now, {
      allowStarted: true,
      addedByOrganiser: true,
    });
    if (plan.noop) return { data: { state: participants.find((p) => p.uid === uid)!.state }, notices: [] };

    applyRosterPlan(tx, ref, participants, plan, ctx.now);
    const state = plan.add!.state;
    writeAudit(tx, ref, { actorUid: ctx.uid, action: 'addPlayer', details: { uid, state }, at: ctx.now });
    const notices: Notice[] =
      uid === ctx.uid ? [] : [{ uid, event: { type: 'added_by_organiser', gameId, gameLabel: gameLabel(game) } }];
    return { data: { state }, notices };
  });
}
```

```ts
export async function deleteGameHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  await ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    const result = await tx.get(ctx.db.doc(`results/${gameId}`));
    if (!ctx.isAdmin) assertOrganiser(game, ctx.uid);
    if (result.exists && result.data()!.status === 'final') {
      throw new DomainError('failed-precondition', 'This game has a result. Void the result before deleting it.');
    }
    if (!ctx.isAdmin && (!canDeleteGame(game, participants) || result.exists)) {
      throw new DomainError('failed-precondition', 'Players have joined this game, so cancel it instead — that tells them.');
    }
    for (const p of participants) tx.delete(ref.collection('participants').doc(p.uid));
    tx.delete(ref);
  });
  // Remove anything left under the deleted game (audit entries).
  await ctx.db.recursiveDelete(ctx.db.doc(`games/${gameId}`));
  return { data: { ok: true }, notices: [] };
}
```

```ts
import { DELETED_PLAYER_NAME, DomainError, isRecord, requireId } from '@pw/shared';
import { getAuth } from 'firebase-admin/auth';
import type { DocumentReference } from 'firebase-admin/firestore';
import { getStorage } from 'firebase-admin/storage';
import { cancelGameTx } from './games';
import type { CallContext, HandlerResult, Notice } from './lib/callable';
import { performLeave } from './roster';

export interface AccountDeps {
  deleteAuthUser(uid: string): Promise<void>;
  deleteAvatar(uid: string): Promise<void>;
}

export const liveAccountDeps: AccountDeps = {
  async deleteAuthUser(uid) {
    await getAuth()
      .deleteUser(uid)
      .catch((err: { code?: string }) => {
        if (err.code !== 'auth/user-not-found') throw err;
      });
  },
  async deleteAvatar(uid) {
    await getStorage().bucket().file(`avatars/${uid}.jpg`).delete({ ignoreNotFound: true });
  },
};

async function updateInBatches(db: Firestore, refs: DocumentReference[], data: Record<string, unknown>): Promise<void> {
  for (let i = 0; i < refs.length; i += 400) {
    const batch = db.batch();
    for (const ref of refs.slice(i, i + 400)) batch.update(ref, data);
    await batch.commit();
  }
}

export async function deleteAccount(db: Firestore, uid: string, now: number, deps: AccountDeps): Promise<Notice[]> {
  const notices: Notice[] = [];

  // 1. Anonymise first, so nobody can add this player to a game while we work.
  await db.doc(`players/${uid}`).set(
    {
      displayName: DELETED_PLAYER_NAME,
      displayNameLower: DELETED_PLAYER_NAME.toLowerCase(),
      photoURL: null,
      preferredPosition: null,
      status: 'deleted',
      updatedAt: ts(now),
    },
    { merge: true },
  );

  // 2. Cancel upcoming games they organise.
  const organised = await db.collection('games').where('organiserUid', '==', uid).where('startsAt', '>', ts(now)).get();
  for (const g of organised.docs) {
    if (g.data().status !== 'scheduled') continue;
    notices.push(...(await cancelGameTx(db, g.id, now, uid, () => {})));
  }

  // 3. Leave upcoming games they joined (promotes waitlists, tells organisers).
  const joined = await db
    .collectionGroup('participants')
    .where('uid', '==', uid)
    .where('gameStartsAt', '>', ts(now))
    .get();
  for (const p of joined.docs) {
    const gameId = p.ref.parent.parent!.id;
    try {
      notices.push(...(await performLeave(db, { gameId, uid, now, mode: 'left', actorUid: uid, authorise: () => {} })));
    } catch (err) {
      if (!(err instanceof DomainError)) throw err; // e.g. a cancelled game: nothing to leave
    }
  }

  // 4. Anonymise remaining name snapshots.
  const participations = await db.collectionGroup('participants').where('uid', '==', uid).orderBy('gameStartsAt').get();
  await updateInBatches(db, participations.docs.map((d) => d.ref), { displayName: DELETED_PLAYER_NAME });
  const allOrganised = await db.collection('games').where('organiserUid', '==', uid).orderBy('startsAt').get();
  await updateInBatches(db, allOrganised.docs.map((d) => d.ref), { organiserName: DELETED_PLAYER_NAME });

  // 5. Delete private data. onUserWrite ignores the users-doc deletion.
  await db.recursiveDelete(db.doc(`users/${uid}`));
  await deps.deleteAvatar(uid);
  await deps.deleteAuthUser(uid);
  return notices;
}

export async function deleteAccountHandler(
  ctx: CallContext,
  raw: unknown,
  deps: AccountDeps = liveAccountDeps,
): Promise<HandlerResult<{ ok: true }>> {
  let target = ctx.uid;
  if (isRecord(raw) && raw.uid !== undefined && raw.uid !== ctx.uid) {
    if (!ctx.isAdmin) throw new DomainError('permission-denied', 'You can only delete your own account.');
    target = requireId(raw, 'uid');
  }
  const notices = await deleteAccount(ctx.db, target, ctx.now, deps);
  return { data: { ok: true }, notices };
}
```

```ts
import { doc, updateDoc } from 'firebase/firestore';
import { getDownloadURL, ref, uploadBytes } from 'firebase/storage';
import { db, storage } from '../firebase';

export function centreSquare(width: number, height: number): { sx: number; sy: number; size: number } {
  const size = Math.min(width, height);
  return { sx: Math.round((width - size) / 2), sy: Math.round((height - size) / 2), size };
}

export async function resizeToJpeg(file: File, size = 256): Promise<Blob> {
  const bitmap = await createImageBitmap(file);
  const crop = centreSquare(bitmap.width, bitmap.height);
  const canvas = document.createElement('canvas');
  canvas.width = size;
  canvas.height = size;
  canvas.getContext('2d')!.drawImage(bitmap, crop.sx, crop.sy, crop.size, crop.size, 0, 0, size, size);
  return new Promise((resolve, reject) =>
    canvas.toBlob((blob) => (blob ? resolve(blob) : reject(new Error('Could not read that image.'))), 'image/jpeg', 0.85),
  );
}

export async function uploadAvatar(uid: string, file: File): Promise<string> {
  const blob = await resizeToJpeg(file);
  const target = ref(storage, `avatars/${uid}.jpg`);
  await uploadBytes(target, blob, { contentType: 'image/jpeg' });
  const url = await getDownloadURL(target);
  await updateDoc(doc(db, 'users', uid), { photoURL: url });
  return url;
}
```

```tsx
export function AddPlayer({ gameId, disabled }: { gameId: string; disabled: boolean }) {

            endAt(`${q}`),

          </li>

      </ul>
```
