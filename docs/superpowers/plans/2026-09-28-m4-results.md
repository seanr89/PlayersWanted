# M4 — Results, Elo & Leaderboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let organisers record a match result (score, lineups, no-shows, optional goals) that locks the game and updates Elo ratings and stats. Add correction and voiding, area leaderboards, player history, awaiting-result nudges and minimal admin tools, including a full `recomputeRatings` replay.

**Architecture:** All rating and stat maths is pure code in `shared/` (`elo.ts`, `results.ts`). Each result stores `ratingChanges[uid] = { before, delta, prevLastResultAt }`, which makes it exactly reversible. A correction reverses the stored result in memory, re-applies the new one, and writes each player once, all in one transaction. `recomputeRatings` replays every final result in `startsAt` order through the same pure functions. Results live in a top-level `results/{gameId}` collection (public read) so player history is a single `array-contains` query.

**Tech Stack:** As M1–M3.

**Spec:** `docs/superpowers/specs/2026-09-27-players-wanted-match-management-design.md` (sections Entity Lifecycles, Result, Submission rules, Corrections and voids, Ratings (Elo), Leaderboard, Notifications, Screens 1–4/7/8, milestone M4). Builds on the M1–M3 plans in this folder.

**Prerequisite:** M3 merged.

## Global Constraints

Everything in the M1–M3 Global Constraints, plus:

- `game.status` gains `"completed"`. A completed game is **locked**: roster, teams and details cannot change (`assertOpen` and `planJoin` enforce it). **Exception:** `setPaid` stays allowed on completed games, because organisers mostly collect money after the match. This is a deliberate deviation, listed in the roadmap.
- Submit only when `status == "scheduled"` **and** `startsAt + durationMins` has passed.
- Scores are integers **0–99**. Lineups are disjoint, and every lineup uid is a participant (confirmed or waitlisted). Deleted players are rejected. `noShows` ⊆ confirmed participants not in a lineup. **Every confirmed participant must be in A, B or `noShows`.** Goals are optional, only for lineup players, and each side's goals must be ≤ that side's score.
- **Rated** only if each lineup has **≥ 3 players** and sizes differ by **≤ 1**. Unrated results still count toward games played, W/D/L and goals.
- Elo: team averages; `E_A = 1 / (1 + 10^((R_B − R_A)/400))`; `S_A ∈ {1, 0.5, 0}`; `G = 1` when gd ≤ 1, else `min(2, 1 + ln(gd)/2)`; `Δ = round(K × G × (S_A − E_A))`, **K = 32**; lineup A gets **+Δ**, lineup B **−Δ**; no-shows are not rated. Rounding is half away from zero, and −0 is normalised to 0.
- Calibration: `ratedGames < 3` hides the rating ("Calibrating (n/3)") and excludes the player from leaderboards. The hidden rating is still used for auto-balance and Elo.
- Corrections and voids by the organiser only **within 72 hours** of first submission **and** only while no player in the old or new lineups has a later result. Otherwise the error is `failed-precondition` with "Ask an admin to correct this result". Admins can always correct or void; when the chain is broken the response says `needsRecompute: true`.
- Leaderboard: calibrated, active players whose `homeAreaId` is the area, sorted by rating, top 200. Other sorts happen on the client. Win % = wins / (W + D + L), shown once `gamesPlayed ≥ 3`. Players with no result in **90 days** are hidden unless "Show inactive" is on.
- Awaiting-result nudge: one notification to the organiser when a game is still `scheduled` **24h after it ended**. It uses `resultNudgeSentAt` and runs in the existing 15-minute schedule.

## Spec Deviation to Confirm

`players.calibrated: bool` (true once `ratedGames ≥ 3`) is added so the leaderboard can use an **equality** filter plus `orderBy(rating)`. The spec's index (`homeAreaId, status, ratedGames ASC, rating DESC`) implies a range filter on `ratedGames` while ordering by `rating`, which Firestore does not serve efficiently. Result functions and `recomputeRatings` keep `calibrated` in sync.

## Review Focus

1. **Two organiser phones submitting the result at the same moment** → exactly one succeeds, and the other gets "A result has already been submitted." → Task 6 test.

```ts
import { BASE_RATING } from './players';

export const K_FACTOR = 32;

export function goalDiffMultiplier(scoreA: number, scoreB: number): number {
  const gd = Math.abs(scoreA - scoreB);
  return gd <= 1 ? 1 : Math.min(2, 1 + Math.log(gd) / 2);
}

export function expectedScore(ratingA: number, ratingB: number): number {
  return 1 / (1 + 10 ** ((ratingB - ratingA) / 400));
}

export function roundHalfAwayFromZero(x: number): number {
  const r = Math.sign(x) * Math.round(Math.abs(x));
  return r === 0 ? 0 : r;
}

/** Rating change for team A. Team B receives the negation. */
export function eloDelta(avgA: number, avgB: number, scoreA: number, scoreB: number): number {
  const actual = scoreA > scoreB ? 1 : scoreA === scoreB ? 0.5 : 0;
  return roundHalfAwayFromZero(K_FACTOR * goalDiffMultiplier(scoreA, scoreB) * (actual - expectedScore(avgA, avgB)));
}

export function rateGame(
  lineups: { A: string[]; B: string[] },
  ratings: Record<string, number>,
  scoreA: number,
  scoreB: number,
): Record<string, number> {
  const avg = (uids: string[]) => uids.reduce((s, u) => s + (ratings[u] ?? BASE_RATING), 0) / uids.length;
  const delta = eloDelta(avg(lineups.A), avg(lineups.B), scoreA, scoreB);
  const out: Record<string, number> = {};
  for (const u of lineups.A) out[u] = delta;
  for (const u of lineups.B) out[u] = delta === 0 ? 0 : -delta;
  return out;
}

export function formatDelta(n: number): string {
  if (n > 0) return `+${n}`;
  if (n < 0) return `−${Math.abs(n)}`;
  return '±0';
}
```

```ts
import { DomainError } from './errors';
import type { Teams } from './teams';
import type { Game, Participant } from './types';
import { isRecord } from './validation';

export interface Lineups {
  A: string[];
  B: string[];
}

export interface ResultInput {
  scoreA: number;
  scoreB: number;
  lineups: Lineups;
  noShows: string[];
  goals: Record<string, number>;
}

export const MIN_RATED_TEAM_SIZE = 3;

const invalid = (message: string): never => {
  throw new DomainError('invalid-argument', message);
};
const precondition = (message: string): never => {
  throw new DomainError('failed-precondition', message);
};

function intIn(v: unknown, min: number, max: number, message: string): number {
  if (typeof v !== 'number' || !Number.isInteger(v) || v < min || v > max) invalid(message);
  return v as number;
}

function uidList(v: unknown, label: string): string[] {
  if (!Array.isArray(v) || v.some((x) => typeof x !== 'string' || x.length === 0 || x.includes('/'))) {
    invalid(`${label} must be a list of players.`);
  }
  const list = v as string[];
  if (new Set(list).size !== list.length) invalid(`${label} lists a player twice.`);
  return list;
}

export function parseResultInput(raw: unknown): ResultInput {
  if (!isRecord(raw)) return invalid('Result details are missing.');
  const scoreA = intIn(raw.scoreA, 0, 99, 'Scores must be whole numbers from 0 to 99.');
  const scoreB = intIn(raw.scoreB, 0, 99, 'Scores must be whole numbers from 0 to 99.');
  if (!isRecord(raw.lineups)) return invalid('Lineups are missing.');
  const lineups = { A: uidList(raw.lineups.A, 'Team A'), B: uidList(raw.lineups.B, 'Team B') };
  const noShows = raw.noShows === undefined || raw.noShows === null ? [] : uidList(raw.noShows, 'No-shows');
  const goals: Record<string, number> = {};
  if (raw.goals !== undefined && raw.goals !== null) {
    if (!isRecord(raw.goals)) return invalid('Goals must map players to numbers.');
    for (const [uid, n] of Object.entries(raw.goals)) {
      const count = intIn(n, 0, 99, 'Goals must be whole numbers from 0 to 99.');
      if (count > 0) goals[uid] = count;
    }
  }
  return { scoreA, scoreB, lineups, noShows, goals };
}

export function isRated(lineups: Lineups): boolean {
  return (
    lineups.A.length >= MIN_RATED_TEAM_SIZE &&
    lineups.B.length >= MIN_RATED_TEAM_SIZE &&
    Math.abs(lineups.A.length - lineups.B.length) <= 1
  );
}

export function assertCanSubmit(game: Game, now: number): void {
  if (game.status === 'cancelled') precondition('This game was cancelled.');
  if (game.status === 'completed') precondition('A result has already been submitted.');
  if (now < game.startsAt + game.durationMins * 60_000) precondition('You can submit the result once the game has finished.');
}

export function validateResult(input: ResultInput, participants: Participant[], unavailable: Set<string>): void {
  const { A, B } = input.lineups;
  if (A.length === 0 || B.length === 0) precondition('Each team needs at least one player.');
  const inA = new Set(A);
  const inB = new Set(B);
  if (B.some((u) => inA.has(u))) invalid('A player can only be on one team.');

  const byUid = new Map(participants.map((p) => [p.uid, p]));
  for (const uid of [...A, ...B]) {
    if (!byUid.has(uid)) precondition('Everyone in the lineups must be on the roster. Add them with "Add a player" first.');
    if (unavailable.has(uid)) precondition(`${byUid.get(uid)!.displayName} can't be included — their account was deleted.`);
  }

  const noShows = new Set(input.noShows);
  for (const uid of noShows) {
    const p = byUid.get(uid);
    if (!p || p.state !== 'confirmed') invalid('Only confirmed players can be marked as no-shows.');
    if (inA.has(uid) || inB.has(uid)) invalid("A player who played can't also be a no-show.");
  }

  const undecided = participants.filter(
    (p) => p.state === 'confirmed' && !inA.has(p.uid) && !inB.has(p.uid) && !noShows.has(p.uid),
  );
  if (undecided.length > 0) {
    const who = undecided.length === 1 ? undecided[0].displayName : `${undecided.length} confirmed players`;
    precondition(`Decide whether ${who} played or didn't show.`);
  }

  let goalsA = 0;
  let goalsB = 0;
  for (const [uid, n] of Object.entries(input.goals)) {
    if (inA.has(uid)) goalsA += n;
    else if (inB.has(uid)) goalsB += n;
    else invalid('Goals can only be given to players in the lineups.');
  }
  if (goalsA > input.scoreA || goalsB > input.scoreB) invalid("A team's goals can't add up to more than its score.");
}

export function scoreLine(teams: Teams, scoreA: number, scoreB: number): string {
  return `${teams.A.name} ${scoreA}–${scoreB} ${teams.B.name}`;
}
```

```ts
export interface RatingChange {
  before: number;
  delta: number;
  prevLastResultAt: number | null;
}

export type ResultStatus = 'final' | 'voided';

export interface GameResult {
  gameId: string;
  areaId: string;
  startsAt: number;
  scoreA: number;
  scoreB: number;
  lineups: Lineups;
  playerUids: string[];
  noShows: string[];
  goals: Record<string, number>;
  rated: boolean;
  ratingChanges: Record<string, RatingChange>;
  version: number;
  status: ResultStatus;
  submittedBy: string;
  submittedAt: number;
  correctedAt: number | null;
  voidedAt: number | null;
  voidReason: string | null;
}

export interface PlayerState {
  stats: PlayerStats;
  lastResultAt: number | null;
}

export interface BuildMeta {
  game: Pick<Game, 'id' | 'areaId' | 'startsAt'>;
  players: Record<string, { rating: number; lastResultAt: number | null }>;
  submittedBy: string;
  now: number;
  version: number;
  submittedAt?: number;
  correctedAt?: number | null;
}

const STAT_KEYS = Object.keys(INITIAL_STATS) as (keyof PlayerStats)[];
const ZERO: PlayerStats = Object.fromEntries(STAT_KEYS.map((k) => [k, 0])) as unknown as PlayerStats;

export function buildResult(input: ResultInput, meta: BuildMeta): GameResult {
  const { lineups } = input;
  const playerUids = [...lineups.A, ...lineups.B];
  const rated = isRated(lineups);
  const ratings = Object.fromEntries(playerUids.map((u) => [u, meta.players[u]?.rating ?? BASE_RATING]));
  const deltas = rated ? rateGame(lineups, ratings, input.scoreA, input.scoreB) : {};
  const ratingChanges = Object.fromEntries(
    playerUids.map((u) => [u, { before: ratings[u], delta: deltas[u] ?? 0, prevLastResultAt: meta.players[u]?.lastResultAt ?? null }]),
  );
  return {
    gameId: meta.game.id,
    areaId: meta.game.areaId,
    startsAt: meta.game.startsAt,
    scoreA: input.scoreA,
    scoreB: input.scoreB,
    lineups: { A: [...lineups.A], B: [...lineups.B] },
    playerUids,
    noShows: [...input.noShows],
    goals: { ...input.goals },
    rated,
    ratingChanges,
    version: meta.version,
    status: 'final',
    submittedBy: meta.submittedBy,
    submittedAt: meta.submittedAt ?? meta.now,
    correctedAt: meta.correctedAt ?? null,
    voidedAt: null,
    voidReason: null,
  };
}

export function ratingDeltaFor(result: GameResult, uid: string): number | null {
  if (!result.rated || !(uid in result.ratingChanges)) return null;
  return result.ratingChanges[uid].delta;
}

export function deltasFromResult(result: GameResult): Record<string, PlayerStats> {
  const out: Record<string, PlayerStats> = {};
  const sides: ['A' | 'B', number][] = [
    ['A', Math.sign(result.scoreA - result.scoreB)],
    ['B', Math.sign(result.scoreB - result.scoreA)],
  ];
  for (const [side, outcome] of sides) {
    for (const uid of result.lineups[side]) {
      out[uid] = {
        ...ZERO,
        gamesPlayed: 1,
        wins: outcome > 0 ? 1 : 0,
        draws: outcome === 0 ? 1 : 0,
        losses: outcome < 0 ? 1 : 0,
        goals: result.goals[uid] ?? 0,
        rating: result.rated ? result.ratingChanges[uid].delta : 0,
        ratedGames: result.rated ? 1 : 0,
      };
    }
  }
  for (const uid of result.noShows) out[uid] = { ...ZERO, noShows: 1 };
  return out;
}

function addStats(a: PlayerStats, b: PlayerStats, sign: 1 | -1): PlayerStats {
  return Object.fromEntries(STAT_KEYS.map((k) => [k, a[k] + sign * b[k]])) as unknown as PlayerStats;
}

export function applyResultToStates(states: Record<string, PlayerState>, result: GameResult): Record<string, PlayerState> {
  const next = { ...states };
  for (const [uid, delta] of Object.entries(deltasFromResult(result))) {
    const current = next[uid] ?? { stats: INITIAL_STATS, lastResultAt: null };
    const played = delta.gamesPlayed > 0;
    next[uid] = {
      stats: addStats(current.stats, delta, 1),
      lastResultAt: played ? Math.max(current.lastResultAt ?? Number.NEGATIVE_INFINITY, result.startsAt) : current.lastResultAt,
    };
  }
  return next;
}

export function reverseResultFromStates(states: Record<string, PlayerState>, result: GameResult): Record<string, PlayerState> {
  const next = { ...states };
  for (const [uid, delta] of Object.entries(deltasFromResult(result))) {
    const current = next[uid];
    if (!current) throw new Error(`Cannot reverse result ${result.gameId}: no stats for ${uid}`);
    const played = delta.gamesPlayed > 0;
    next[uid] = {
      stats: addStats(current.stats, delta, -1),
      lastResultAt:
        played && current.lastResultAt === result.startsAt ? result.ratingChanges[uid].prevLastResultAt : current.lastResultAt,
    };
  }
  return next;
}

export function replayResults(results: GameResult[]): {
  states: Record<string, PlayerState>;
  ratingChanges: Record<string, Record<string, RatingChange>>;
} {
  let states: Record<string, PlayerState> = {};
  const ratingChanges: Record<string, Record<string, RatingChange>> = {};
  const ordered = results
    .filter((r) => r.status === 'final')
    .sort((a, b) => a.startsAt - b.startsAt || a.gameId.localeCompare(b.gameId));
  for (const r of ordered) {
    const players = Object.fromEntries(
      Object.entries(states).map(([u, s]) => [u, { rating: s.stats.rating, lastResultAt: s.lastResultAt }]),
    );
    const rebuilt = buildResult(
      { scoreA: r.scoreA, scoreB: r.scoreB, lineups: r.lineups, noShows: r.noShows, goals: r.goals },
      { game: { id: r.gameId, areaId: r.areaId, startsAt: r.startsAt }, players, submittedBy: r.submittedBy, now: r.submittedAt, version: r.version },
    );
    ratingChanges[r.gameId] = rebuilt.ratingChanges;
    states = applyResultToStates(states, rebuilt);
  }
  return { states, ratingChanges };
}

export function resultFromData(d: Record<string, unknown>): GameResult {
  const lineups = (d.lineups ?? { A: [], B: [] }) as Lineups;
  return {
    gameId: d.gameId as string,
    areaId: d.areaId as string,
    startsAt: toMillis(d.startsAt)!,
    scoreA: d.scoreA as number,
    scoreB: d.scoreB as number,
    lineups,
    playerUids: (d.playerUids as string[] | undefined) ?? [...lineups.A, ...lineups.B],
    noShows: (d.noShows as string[] | undefined) ?? [],
    goals: (d.goals as Record<string, number> | undefined) ?? {},
    rated: Boolean(d.rated),
    ratingChanges: (d.ratingChanges as Record<string, RatingChange> | undefined) ?? {},
    version: (d.version as number | undefined) ?? 1,
    status: d.status === 'voided' ? 'voided' : 'final',
    submittedBy: d.submittedBy as string,
    submittedAt: toMillis(d.submittedAt)!,
    correctedAt: toMillis(d.correctedAt),
    voidedAt: toMillis(d.voidedAt),
    voidReason: (d.voidReason as string | undefined) ?? null,
  };
}
```

`ratingChanges[*].prevLastResultAt` is stored as epoch milliseconds (a number), not a Firestore timestamp, because it lives inside a nested map that only functions read.

```ts
import {
  applyResultToStates,
  assertCanSubmit,
  buildResult,
  DomainError,
  gameLabel,
  isCalibrated,
  parseResultInput,
  playerFromData,
  ratingDeltaFor,
  requireId,
  resultFromData,
  scoreLine,
  validateResult,
  type Game,
  type GameResult,
  type Participant,
  type Player,
  type PlayerState,
  type PlayerStats,
} from '@pw/shared';
import { FieldValue, type DocumentReference, type Firestore, type Transaction } from 'firebase-admin/firestore';
import { writeAudit } from './lib/audit';
import type { CallContext, HandlerResult, Notice } from './lib/callable';
import { resultToData, ts } from './lib/convert';
import { assertOrganiser, loadGameTx } from './lib/games-tx';

export interface LoadedPlayer {
  ref: DocumentReference;
  player: Player | null;
}

export async function loadPlayers(tx: Transaction, db: Firestore, uids: string[]): Promise<Map<string, LoadedPlayer>> {
  const unique = [...new Set(uids)];
  if (unique.length === 0) return new Map();
  const refs = unique.map((u) => db.doc(`players/${u}`));
  const snaps = await tx.getAll(...refs);
  return new Map(unique.map((u, i) => [u, { ref: refs[i], player: snaps[i].exists ? playerFromData(u, snaps[i].data()!) : null }]));
}

function pickStats(p: Player): PlayerStats {
  const { rating, ratedGames, wins, draws, losses, goals, gamesPlayed, noShows } = p;
  return { rating, ratedGames, wins, draws, losses, goals, gamesPlayed, noShows };
}

export function statesOf(loaded: Map<string, LoadedPlayer>): Record<string, PlayerState> {
  const out: Record<string, PlayerState> = {};
  for (const [uid, { player }] of loaded) if (player) out[uid] = { stats: pickStats(player), lastResultAt: player.lastResultAt };
  return out;
}

export function unavailableOf(loaded: Map<string, LoadedPlayer>): Set<string> {
  return new Set([...loaded].filter(([, l]) => !l.player || l.player.status === 'deleted').map(([uid]) => uid));
}

export function ratingInfo(states: Record<string, PlayerState>) {
  return Object.fromEntries(Object.entries(states).map(([u, s]) => [u, { rating: s.stats.rating, lastResultAt: s.lastResultAt }]));
}

export function writeStates(
  tx: Transaction,
  loaded: Map<string, LoadedPlayer>,
  before: Record<string, PlayerState>,
  after: Record<string, PlayerState>,
  now: number,
): void {
  for (const [uid, state] of Object.entries(after)) {
    if (JSON.stringify(before[uid]) === JSON.stringify(state)) continue;
    tx.update(loaded.get(uid)!.ref, {
      ...state.stats,
      calibrated: isCalibrated(state.stats),
      lastResultAt: ts(state.lastResultAt),
      updatedAt: ts(now),
    });
  }
}

export function writeAttendance(tx: Transaction, gameRef: DocumentReference, participants: Participant[], result: GameResult | null): void {
  const played = new Set(result?.playerUids ?? []);
  const noShows = new Set(result?.noShows ?? []);
  for (const p of participants) {
    const next = played.has(p.uid) ? 'played' : noShows.has(p.uid) ? 'no_show' : null;
    if (p.attendance === next) continue;
    tx.update(gameRef.collection('participants').doc(p.uid), { attendance: next ?? FieldValue.delete() });
  }
}

export function chainBroken(loaded: Map<string, LoadedPlayer>, uids: string[], startsAt: number): boolean {
  return uids.some((u) => {
    const last = loaded.get(u)?.player?.lastResultAt ?? null;
    return last !== null && last > startsAt;
  });
}

export function summaryOf(result: GameResult) {
  return { scoreA: result.scoreA, scoreB: result.scoreB, rated: result.rated, submittedAt: ts(result.submittedAt) };
}

export function resultNotices(
  type: 'result_submitted' | 'result_corrected',
  game: Game,
  result: GameResult,
  only?: Set<string>,
): Notice[] {
  const line = scoreLine(game.teams, result.scoreA, result.scoreB);
  const label = gameLabel(game);
  return result.playerUids
    .filter((uid) => !only || only.has(uid))
    .map((uid) => ({ uid, event: { type, gameId: game.id, gameLabel: label, scoreLine: line, ratingDelta: ratingDeltaFor(result, uid) } }));
}

export async function submitResultHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true; rated: boolean }>> {
  const gameId = requireId(raw, 'gameId');
  const input = parseResultInput(raw);
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    const resultRef = ctx.db.doc(`results/${gameId}`);
    const existing = await tx.get(resultRef);
    const loaded = await loadPlayers(tx, ctx.db, [...input.lineups.A, ...input.lineups.B, ...input.noShows]);

    if (!ctx.isAdmin) assertOrganiser(game, ctx.uid);
    assertCanSubmit(game, ctx.now);
    const previous = existing.exists ? resultFromData(existing.data()!) : null;
    if (previous?.status === 'final') throw new DomainError('failed-precondition', 'A result has already been submitted.');
    validateResult(input, participants, unavailableOf(loaded));

    const before = statesOf(loaded);
    const result = buildResult(input, {
      game,
      players: ratingInfo(before),
      submittedBy: ctx.uid,
      now: ctx.now,
      version: (previous?.version ?? 0) + 1,
    });
    writeStates(tx, loaded, before, applyResultToStates(before, result), ctx.now);
    tx.set(resultRef, resultToData(result));
    tx.update(ref, { status: 'completed', resultSummary: summaryOf(result), updatedAt: ts(ctx.now) });
    writeAttendance(tx, ref, participants, result);
    writeAudit(tx, ref, {
      actorUid: ctx.uid,
      action: 'submitResult',
      details: { scoreA: result.scoreA, scoreB: result.scoreB, rated: result.rated },
      at: ctx.now,
    });
    return { data: { ok: true as const, rated: result.rated }, notices: resultNotices('result_submitted', game, result) };
  });
}
```

```ts
export const CORRECTION_WINDOW_MS = 72 * 3_600_000;

function assertOrganiserMayChange(result: GameResult, broken: boolean, now: number): void {
  if (now - result.submittedAt > CORRECTION_WINDOW_MS || broken) {
    throw new DomainError('failed-precondition', 'This result can no longer be changed here. Ask an admin to correct this result.');
  }
}

async function loadFinalResult(tx: Transaction, db: Firestore, game: Game): Promise<{ ref: DocumentReference; result: GameResult }> {
  const ref = db.doc(`results/${game.id}`);
  const snap = await tx.get(ref);
  const result = snap.exists ? resultFromData(snap.data()!) : null;
  if (game.status !== 'completed' || !result || result.status !== 'final') {
    throw new DomainError('failed-precondition', 'There is no result to change.');
  }
  return { ref, result };
}

export async function correctResultHandler(
  ctx: CallContext,
  raw: unknown,
): Promise<HandlerResult<{ ok: true; needsRecompute: boolean }>> {
  const gameId = requireId(raw, 'gameId');
  const input = parseResultInput(raw);
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    const { ref: resultRef, result: old } = await loadFinalResult(tx, ctx.db, game);
    const loaded = await loadPlayers(tx, ctx.db, [
      ...old.playerUids,
      ...old.noShows,
      ...input.lineups.A,
      ...input.lineups.B,
      ...input.noShows,
    ]);

    if (!ctx.isAdmin) assertOrganiser(game, ctx.uid);
    validateResult(input, participants, unavailableOf(loaded));
    const broken = chainBroken(loaded, [...old.playerUids, ...input.lineups.A, ...input.lineups.B], game.startsAt);
    if (!ctx.isAdmin) assertOrganiserMayChange(old, broken, ctx.now);

    const before = statesOf(loaded);
    const reversed = reverseResultFromStates(before, old);
    const result = buildResult(input, {
      game,
      players: ratingInfo(reversed),
      submittedBy: old.submittedBy,
      submittedAt: old.submittedAt,
      correctedAt: ctx.now,
      now: ctx.now,
      version: old.version + 1,
    });
    writeStates(tx, loaded, before, applyResultToStates(reversed, result), ctx.now);
    tx.set(resultRef, resultToData(result));
    tx.update(ref, { resultSummary: summaryOf(result), updatedAt: ts(ctx.now) });
    writeAttendance(tx, ref, participants, result);
    writeAudit(tx, ref, { actorUid: ctx.uid, action: 'correctResult', details: { version: result.version }, at: ctx.now });

    const affected = new Set(
      [...new Set([...old.playerUids, ...result.playerUids])].filter((u) => ratingDeltaFor(old, u) !== ratingDeltaFor(result, u)),
    );
    const notices = resultNotices('result_corrected', game, result, affected);
    // Players dropped from the lineups also get told.
    for (const uid of affected) {
      if (!result.playerUids.includes(uid)) {
        notices.push({
          uid,
          event: { type: 'result_corrected', gameId, gameLabel: gameLabel(game), scoreLine: scoreLine(game.teams, result.scoreA, result.scoreB), ratingDelta: null },
        });

export async function voidResultHandler(
  ctx: CallContext,
  raw: unknown,
): Promise<HandlerResult<{ ok: true; needsRecompute: boolean }>> {
  const gameId = requireId(raw, 'gameId');
  const reason = isRecord(raw) && typeof raw.reason === 'string' ? raw.reason.trim() : '';
  if (reason.length === 0 || reason.length > 200) throw new DomainError('invalid-argument', 'Give a reason (up to 200 characters).');
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    const { ref: resultRef, result: old } = await loadFinalResult(tx, ctx.db, game);
    const loaded = await loadPlayers(tx, ctx.db, [...old.playerUids, ...old.noShows]);

    if (!ctx.isAdmin) assertOrganiser(game, ctx.uid);
    const broken = chainBroken(loaded, old.playerUids, game.startsAt);
    if (!ctx.isAdmin) assertOrganiserMayChange(old, broken, ctx.now);

    const before = statesOf(loaded);
    writeStates(tx, loaded, before, reverseResultFromStates(before, old), ctx.now);
    tx.update(resultRef, { status: 'voided', voidedAt: ts(ctx.now), voidReason: reason });
    tx.update(ref, { status: 'scheduled', resultSummary: null, updatedAt: ts(ctx.now) });
    writeAttendance(tx, ref, participants, null);
    writeAudit(tx, ref, { actorUid: ctx.uid, action: 'voidResult', details: { reason }, at: ctx.now });

    const label = gameLabel(game);
    const notices: Notice[] = old.playerUids.map((uid) => ({ uid, event: { type: 'result_voided' as const, gameId, gameLabel: label } }));
    return { data: { ok: true as const, needsRecompute: broken }, notices };
  });
}
```

```ts
const DAY = 24 * HOUR;
const NUDGE_AFTER_END_MS = 24 * HOUR;
const NUDGE_LOOKBACK_MS = 14 * DAY;

export async function runResultNudges(db: Firestore, now: number): Promise<Notice[]> {
  const candidates = await db
    .collection('games')
    .where('status', '==', 'scheduled')
    .where('startsAt', '>=', ts(now - NUDGE_LOOKBACK_MS))
    .where('startsAt', '<=', ts(now - NUDGE_AFTER_END_MS))
    .get();

  const notices: Notice[] = [];
  for (const candidate of candidates.docs) {
    const game = await db.runTransaction(async (tx) => {
      const fresh = await tx.get(candidate.ref);
      const g = gameFromData(fresh.id, fresh.data()!);
      const endsAt = g.startsAt + g.durationMins * 60_000;
      if (g.status !== 'scheduled' || g.resultNudgeSentAt !== null || now < endsAt + NUDGE_AFTER_END_MS) return null;
      tx.update(candidate.ref, { resultNudgeSentAt: ts(now) });
      return g.confirmedCount >= 2 ? g : null; // mark empty games too, so they aren't rescanned
    });
    if (game) notices.push({ uid: game.organiserUid, event: { type: 'result_nudge', gameId: game.id, gameLabel: gameLabel(game) } });
  }
  return notices;
}
```

```ts
import { DomainError, INITIAL_STATS, isCalibrated, replayResults, resultFromData } from '@pw/shared';

async function commitInBatches(db: Firestore, writes: { ref: DocumentReference; data: Record<string, unknown> }[]) {
  for (let i = 0; i < writes.length; i += 400) {
    const batch = db.batch();
    for (const w of writes.slice(i, i + 400)) batch.update(w.ref, w.data);
    await batch.commit();
  }
}

/** Resets every player to 1200 / zero stats and replays every final result in kick-off order. Run when the app is quiet. */
export async function recomputeAllRatings(db: Firestore, now: number): Promise<{ players: number; results: number }> {
  const resultDocs = (await db.collection('results').where('status', '==', 'final').get()).docs;
  const results = resultDocs.map((d) => resultFromData(d.data()));
  const { states, ratingChanges } = replayResults(results);

  const players = await db.collection('players').get();
  const playerWrites = players.docs.map((d) => {
    const state = states[d.id] ?? { stats: INITIAL_STATS, lastResultAt: null };
    return {
      ref: d.ref,
      data: { ...state.stats, calibrated: isCalibrated(state.stats), lastResultAt: ts(state.lastResultAt), updatedAt: ts(now) },
    };
  });
  const resultWrites = resultDocs.map((d) => ({ ref: d.ref, data: { ratingChanges: ratingChanges[d.id] } }));

  await commitInBatches(db, [...playerWrites, ...resultWrites]);
  return { players: players.size, results: results.length };
}

export async function recomputeRatingsHandler(ctx: CallContext): Promise<HandlerResult<{ players: number; results: number }>> {
  if (!ctx.isAdmin) throw new DomainError('permission-denied', 'Only admins can recompute ratings.');
  return { data: await recomputeAllRatings(ctx.db, ctx.now), notices: [] };
}
```

```ts
import type { GameResult, Participant, ResultInput } from '@pw/shared';

export type Place = 'A' | 'B' | 'noshow' | 'bench' | 'undecided';

export interface ResultDraft {
  scoreA: number;
  scoreB: number;
  places: Record<string, Place>;
  goals: Record<string, number>;
}

export function placeOptions(p: Participant): Place[] {
  return p.state === 'confirmed' ? ['A', 'B', 'noshow'] : ['A', 'B', 'bench'];
}

export function initialDraft(participants: Participant[], existing: GameResult | null): ResultDraft {
  const places: Record<string, Place> = {};
  if (existing) {
    for (const u of existing.lineups.A) places[u] = 'A';
    for (const u of existing.lineups.B) places[u] = 'B';
    for (const u of existing.noShows) places[u] = 'noshow';
  }
  for (const p of participants) {
    if (places[p.uid]) continue;
    if (p.state === 'waitlisted') places[p.uid] = 'bench';
    else places[p.uid] = existing ? 'undecided' : (p.teamId ?? 'undecided');
  }
  return {
    scoreA: existing?.scoreA ?? 0,
    scoreB: existing?.scoreB ?? 0,
    places,
    goals: { ...(existing?.goals ?? {}) },
  };
}

export function draftToInput(draft: ResultDraft): ResultInput {
  const uidsAt = (place: Place) => Object.keys(draft.places).filter((u) => draft.places[u] === place);
  const A = uidsAt('A');
  const B = uidsAt('B');
  const inLineup = new Set([...A, ...B]);
  const goals = Object.fromEntries(Object.entries(draft.goals).filter(([u, n]) => inLineup.has(u) && n > 0));
  return { scoreA: draft.scoreA, scoreB: draft.scoreB, lineups: { A, B }, noShows: uidsAt('noshow'), goals };
}
```

```ts
import type { Player } from '@pw/shared';

export type SortKey = 'rating' | 'gamesPlayed' | 'winPct' | 'goals';
const INACTIVE_AFTER_MS = 90 * 86_400_000;

export function winPct(p: Pick<Player, 'wins' | 'draws' | 'losses' | 'gamesPlayed'>): number | null {
  const decided = p.wins + p.draws + p.losses;
  if (p.gamesPlayed < 3 || decided === 0) return null;
  return Math.round((100 * p.wins) / decided);
}

export function isActive(p: Pick<Player, 'lastResultAt'>, now: number): boolean {
  return p.lastResultAt !== null && now - p.lastResultAt <= INACTIVE_AFTER_MS;
}

export function leaderboardRows(
  players: Player[],
  opts: { sort: SortKey; showInactive: boolean; now: number },
): Player[] {
  const value = (p: Player): number => (opts.sort === 'winPct' ? (winPct(p) ?? -1) : p[opts.sort]);
  return players
    .filter((p) => opts.showInactive || isActive(p, opts.now))
    .sort((a, b) => value(b) - value(a) || b.rating - a.rating || a.displayName.localeCompare(b.displayName));
}
```
