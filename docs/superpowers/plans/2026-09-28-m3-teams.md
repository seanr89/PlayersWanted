# M3 — Teams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let organisers split confirmed players into Team A and Team B: by hand, or with a rating-based auto-balance they can tweak. They can name and colour the teams and publish them, and players get notified.

**Architecture:** Team **details** (name, bib colour) live on the game doc as `teams.A` / `teams.B`. Team **membership** lives on each participant doc as `teamId`, so moving a player is a single-document write. `balanceTeams` is a pure function in `shared/`. It searches every split exhaustively up to 16 players and falls back to a snake draft above that. New callables follow the M1 handler pattern. Auto-balance only returns a proposal; saving goes through `assignTeams`.

**Tech Stack:** As M1/M2.

**Spec:** `docs/superpowers/specs/2026-09-27-players-wanted-match-management-design.md` (sections Team, Auto-balance, Notifications, Screens 1, milestone M3). Builds on the M1 and M2 plans in this folder.

**Prerequisite:** M2 merged (`players/{uid}.rating` and `preferredPosition` exist; `writeAudit`, `performLeave` with `actorUid` exist).

## Global Constraints

Everything in the M1 and M2 Global Constraints, plus:

- Exactly two teams, ids `"A"` and `"B"`. Defaults: `A = { name: "Bibs", colour: "orange" }`, `B = { name: "Non-bibs", colour: "white" }`.
- Team `name` 1–20 chars (trimmed); `colour` from the fixed palette of 8: `orange, white, red, blue, green, yellow, black, purple`.
- Only **confirmed** participants can have a `teamId`.
- Publishing requires **every confirmed player assigned** and team sizes differing by **≤ 1**.
- Auto-balance: exhaustive search over splits of sizes ⌊n/2⌋ / ⌈n/2⌉ for **n ≤ 16**; **greedy snake draft by rating above 16**. Pick smallest |avg(A) − avg(B)|; tie-break 1: one `GK`-preferring player on each side; tie-break 2: smallest difference in rating spread. New/uncalibrated players use their current rating (1200 default).
- Team edits are allowed until the game is completed (M4 adds that guard through `assertOpen`).
- Notifications: teams published → confirmed players; my team changed after publishing → affected player; a player with a team leaves a published game → organiser ("teams uneven").

## Known Limitation (confirm with product owner)

The spec says that before publishing, **only the organiser sees assignments**. Firestore security rules cannot hide individual fields, and `teamId` sits on participant docs that every signed-in user can read. This plan hides unpublished teams **in the UI only**. If that isn't acceptable, store drafts in an organiser-only `games/{id}/private/teamsDraft` doc and copy them onto participants on publish. That is listed in the roadmap as a decision to confirm.

## Review Focus

1. **Assigning teams in the same second a player leaves** must not leave a `teamId` on a deleted participant or crash: `assignTeams` must reject uids that are no longer confirmed. → Task 1 (`validateAssignments`) and Task 4 test.
2. **Auto-balance on an odd number of players** (e.g. 9 after a drop-out) must give sizes 5 and 4, not fail. → Task 2 test.
3. **Auto-balance with players whose `players` doc is missing** (older accounts before the M2 backfill) must use 1200, not crash. → Task 4 test.
4. **Publishing after a promotion added an unassigned player** must be refused with a clear message naming the problem. → Task 1 (`publishProblem`) and Task 4 test.
5. **Unpublishing** must not notify anyone, while re-publishing does. → Task 4 test.

import { DomainError } from './errors';
import type { Participant } from './types';
import { isRecord } from './validation';

export const TEAM_IDS = ['A', 'B'] as const;
export type TeamId = (typeof TEAM_IDS)[number];

export const TEAM_COLOURS = ['orange', 'white', 'red', 'blue', 'green', 'yellow', 'black', 'purple'] as const;
export type TeamColour = (typeof TEAM_COLOURS)[number];

export interface TeamDetails {
  name: string;
  colour: TeamColour;
}
export type Teams = Record<TeamId, TeamDetails>;

export const DEFAULT_TEAMS: Teams = {
  A: { name: 'Bibs', colour: 'orange' },
  B: { name: 'Non-bibs', colour: 'white' },
};

export function isTeamId(v: unknown): v is TeamId {
  return v === 'A' || v === 'B';
}

export function validateTeamDetails(raw: unknown): { teamId: TeamId; details: TeamDetails } {
  if (!isRecord(raw) || !isTeamId(raw.teamId)) throw new DomainError('invalid-argument', 'Choose team A or B.');
  const name = typeof raw.name === 'string' ? raw.name.trim() : '';
  if (name.length < 1 || name.length > 20) throw new DomainError('invalid-argument', 'Team names must be 1–20 characters.');
  if (typeof raw.colour !== 'string' || !(TEAM_COLOURS as readonly string[]).includes(raw.colour)) {
    throw new DomainError('invalid-argument', 'Choose a colour from the list.');
  }
  return { teamId: raw.teamId, details: { name, colour: raw.colour as TeamColour } };
}

export function validateAssignments(raw: unknown, participants: Participant[]): Record<string, TeamId | null> {
  if (!isRecord(raw)) throw new DomainError('invalid-argument', 'Assignments are missing.');
  const entries = Object.entries(raw);
  if (entries.length === 0 || entries.length > 30) throw new DomainError('invalid-argument', 'Assign between 1 and 30 players.');
  const confirmed = new Set(participants.filter((p) => p.state === 'confirmed').map((p) => p.uid));
  const out: Record<string, TeamId | null> = {};
  for (const [uid, value] of entries) {
    if (value !== null && !isTeamId(value)) throw new DomainError('invalid-argument', 'Teams must be A, B or none.');
    if (!confirmed.has(uid)) {
      throw new DomainError('failed-precondition', 'Only confirmed players can be put on a team. Refresh and try again.');
    }
    out[uid] = value;
  }
  return out;
}

export function publishProblem(participants: Participant[]): string | null {
  const confirmed = participants.filter((p) => p.state === 'confirmed');
  if (confirmed.length < 2) return 'You need at least 2 confirmed players.';
  const unassigned = confirmed.filter((p) => p.teamId === null).length;
  if (unassigned > 0) {
    return unassigned === 1 ? '1 confirmed player still needs a team.' : `${unassigned} confirmed players still need a team.`;
  }
  const a = confirmed.filter((p) => p.teamId === 'A').length;
  const b = confirmed.length - a;
  if (Math.abs(a - b) > 1) return 'Teams must be the same size, or differ by one.';
  return null;
}

```ts
export interface BalanceInput {
  uid: string;
  rating: number;
  preferredPosition: Position | null;
}

export const EXHAUSTIVE_LIMIT = 16;
const EPSILON = 1e-9;

export function teamAverage(uids: string[], ratings: Record<string, number>): number {
  if (uids.length === 0) return 0;
  return uids.reduce((sum, uid) => sum + (ratings[uid] ?? 0), 0) / uids.length;
}

function avg(team: BalanceInput[]): number {
  return team.reduce((s, x) => s + x.rating, 0) / team.length;
}

function spread(team: BalanceInput[]): number {
  const r = team.map((x) => x.rating);
  return Math.max(...r) - Math.min(...r);
}

/** Lower is better, compared left to right. */
function score(a: BalanceInput[], b: BalanceInput[]): [number, number, number] {
  const gkA = a.some((x) => x.preferredPosition === 'GK');
  const gkB = b.some((x) => x.preferredPosition === 'GK');
  return [Math.abs(avg(a) - avg(b)), gkA && gkB ? 0 : 1, Math.abs(spread(a) - spread(b))];
}

function better(x: [number, number, number], y: [number, number, number]): boolean {
  for (let i = 0; i < 3; i++) {
    if (x[i] < y[i] - EPSILON) return true;
    if (x[i] > y[i] + EPSILON) return false;
  }
  return false;
}

function* combinations(indices: number[], k: number, start = 0, picked: number[] = []): Generator<number[]> {
  if (picked.length === k) {
    yield picked;
    return;
  }
  for (let i = start; i <= indices.length - (k - picked.length); i++) {
    yield* combinations(indices, k, i + 1, [...picked, indices[i]]);
  }
}

function snakeDraft(sorted: BalanceInput[]): { A: string[]; B: string[] } {
  const byRating = [...sorted].sort((a, b) => b.rating - a.rating || a.uid.localeCompare(b.uid));
  const A: string[] = [];
  const B: string[] = [];
  byRating.forEach((player, i) => {
    const toA = i % 2 === 0 === (Math.floor(i / 2) % 2 === 0);
    (toA ? A : B).push(player.uid);
  });
  return { A, B };
}

export function balanceTeams(players: BalanceInput[]): { A: string[]; B: string[] } {
  const sorted = [...players].sort((a, b) => a.uid.localeCompare(b.uid));
  const n = sorted.length;
  if (n < 2) return { A: sorted.map((x) => x.uid), B: [] };
  if (n > EXHAUSTIVE_LIMIT) return snakeDraft(sorted);

  const sizeB = Math.floor(n / 2);
  // For even n, keep player 0 in A so mirror-image splits are only tried once.
  const candidates = Array.from({ length: n }, (_, i) => i).filter((i) => n % 2 === 1 || i !== 0);

  let best: { score: [number, number, number]; bSet: Set<number> } | null = null;
  for (const combo of combinations(candidates, sizeB)) {
    const bSet = new Set(combo);
    const a = sorted.filter((_, i) => !bSet.has(i));
    const b = sorted.filter((_, i) => bSet.has(i));
    const s = score(a, b);
    if (!best || better(s, best.score)) best = { score: s, bSet: new Set(combo) };
  }
  return {
    A: sorted.filter((_, i) => !best!.bSet.has(i)).map((x) => x.uid),
    B: sorted.filter((_, i) => best!.bSet.has(i)).map((x) => x.uid),
  };
}

  balanceTeams,
  BASE_RATING,
  DomainError,
  gameLabel,
  isPosition,
  isRecord,
  publishProblem,
  requireId,
  teamAverage,
  validateAssignments,
  validateTeamDetails,
  type BalanceInput,
  type TeamId,
} from '@pw/shared';
import type { CallContext, HandlerResult, Notice } from './lib/callable';
import { writeAudit } from './lib/audit';
import { ts } from './lib/convert';
import { assertOpen, assertOrganiser, loadGameTx } from './lib/games-tx';

export async function updateTeamDetailsHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  const { teamId, details } = validateTeamDetails(raw);
  await ctx.db.runTransaction(async (tx) => {
    const { ref, game } = await loadGameTx(tx, ctx.db, gameId);
    assertOrganiser(game, ctx.uid);
    assertOpen(game);
    tx.update(ref, { [`teams.${teamId}`]: details, updatedAt: ts(ctx.now) });
    writeAudit(tx, ref, { actorUid: ctx.uid, action: 'updateTeamDetails', details: { teamId, ...details }, at: ctx.now });
  });
  return { data: { ok: true }, notices: [] };
}

export async function assignTeamsHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ changed: number }>> {
  const gameId = requireId(raw, 'gameId');
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    assertOrganiser(game, ctx.uid);
    assertOpen(game);
    const assignments = validateAssignments(isRecord(raw) ? raw.assignments : undefined, participants);

    const changed: { uid: string; teamId: TeamId | null }[] = [];
    for (const p of participants) {
      if (!(p.uid in assignments)) continue;
      const next = assignments[p.uid];
      if (p.teamId === next) continue;
      tx.update(ref.collection('participants').doc(p.uid), { teamId: next });
      changed.push({ uid: p.uid, teamId: next });
    }
    if (changed.length > 0) {
      writeAudit(tx, ref, { actorUid: ctx.uid, action: 'assignTeams', details: { changed: changed.length }, at: ctx.now });
    }

    const notices: Notice[] =
      game.teamsPublishedAt === null
        ? []
        : changed.map((c) => ({
            uid: c.uid,
            event: {
              type: 'team_changed' as const,
              gameId,
              gameLabel: gameLabel(game),
              teamName: c.teamId ? game.teams[c.teamId].name : null,
            },
          }));
    return { data: { changed: changed.length }, notices };
  });
}

export async function autoBalanceTeamsHandler(
  ctx: CallContext,
  raw: unknown,
): Promise<HandlerResult<{ A: string[]; B: string[]; averages: { A: number; B: number } }>> {
  const gameId = requireId(raw, 'gameId');
  const { game, participants } = await ctx.db.runTransaction((tx) => loadGameTx(tx, ctx.db, gameId));
  assertOrganiser(game, ctx.uid);
  assertOpen(game);
  const confirmed = participants.filter((p) => p.state === 'confirmed');
  if (confirmed.length < 2) throw new DomainError('failed-precondition', 'You need at least 2 confirmed players.');

  const snaps = await ctx.db.getAll(...confirmed.map((p) => ctx.db.doc(`players/${p.uid}`)));
  const inputs: BalanceInput[] = confirmed.map((p, i) => {
    const d = snaps[i].exists ? snaps[i].data()! : {};
    return {
      uid: p.uid,
      rating: typeof d.rating === 'number' ? d.rating : BASE_RATING,
      preferredPosition: isPosition(d.preferredPosition) ? d.preferredPosition : null,
    };
  });
  const { A, B } = balanceTeams(inputs);
  const ratings = Object.fromEntries(inputs.map((x) => [x.uid, x.rating]));
  return { data: { A, B, averages: { A: teamAverage(A, ratings), B: teamAverage(B, ratings) } }, notices: [] };
}

export async function publishTeamsHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  const publish = isRecord(raw) ? raw.publish : undefined;
  if (typeof publish !== 'boolean') throw new DomainError('invalid-argument', 'publish must be true or false.');
  return ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    assertOrganiser(game, ctx.uid);
    assertOpen(game);
    if (!publish) {
      tx.update(ref, { teamsPublishedAt: null, updatedAt: ts(ctx.now) });
      writeAudit(tx, ref, { actorUid: ctx.uid, action: 'unpublishTeams', at: ctx.now });
      return { data: { ok: true as const }, notices: [] };
    }
    const problem = publishProblem(participants);
    if (problem) throw new DomainError('failed-precondition', problem);
    tx.update(ref, { teamsPublishedAt: ts(ctx.now), updatedAt: ts(ctx.now) });
    writeAudit(tx, ref, { actorUid: ctx.uid, action: 'publishTeams', at: ctx.now });
    const label = gameLabel(game);
    const notices: Notice[] = participants
      .filter((p) => p.state === 'confirmed' && p.teamId !== null)
      .sort((a, b) => a.uid.localeCompare(b.uid))
      .map((p) => ({
        uid: p.uid,
        event: { type: 'teams_published' as const, gameId, gameLabel: label, teamName: game.teams[p.teamId!].name },
      }));
    return { data: { ok: true as const }, notices };
  });
}

export async function clearTeamsHandler(ctx: CallContext, raw: unknown): Promise<HandlerResult<{ ok: true }>> {
  const gameId = requireId(raw, 'gameId');
  await ctx.db.runTransaction(async (tx) => {
    const { ref, game, participants } = await loadGameTx(tx, ctx.db, gameId);
    assertOrganiser(game, ctx.uid);
    assertOpen(game);
    for (const p of participants) {
      if (p.teamId !== null) tx.update(ref.collection('participants').doc(p.uid), { teamId: null });
    }
    tx.update(ref, { teamsPublishedAt: null, updatedAt: ts(ctx.now) });
    writeAudit(tx, ref, { actorUid: ctx.uid, action: 'clearTeams', at: ctx.now });
  });
  return { data: { ok: true }, notices: [] };
}

import type { Participant, TeamColour, TeamId } from '@pw/shared';

export function cycleTeam(current: TeamId | null): TeamId | null {
  if (current === 'A') return 'B';
  if (current === 'B') return null;
  return 'A';
}

export function assignmentDiff(
  participants: Participant[],
  draft: Record<string, TeamId | null>,
): Record<string, TeamId | null> {
  const diff: Record<string, TeamId | null> = {};
  for (const p of participants) {
    if (p.state !== 'confirmed' || !(p.uid in draft)) continue;
    if (draft[p.uid] !== p.teamId) diff[p.uid] = draft[p.uid];
  }
  return diff;
}

        ))}
      </div>

      <p className="muted">Tap a player to move them: {game.teams.A.name} → {game.teams.B.name} → no team.</p>
      <ul className="plain">
        {confirmed.map((p) => {
          const team = draft[p.uid] ?? null;
          return (
            <li key={p.uid}>
              <button
                className="secondary row"
                style={{ width: '100%', marginBottom: 6 }}
                disabled={off}
                onClick={() => setDraft((d) => ({ ...d, [p.uid]: cycleTeam(d[p.uid] ?? null) }))}
              >
                <span>{p.displayName}</span>
                <span className="pill">{team ? game.teams[team].name : 'No team'}</span>
              </button>
            </li>
          );
        })}
      </ul>

      <div className="row" style={{ justifyContent: 'flex-start', flexWrap: 'wrap' }}>
        <button
          className="secondary"
          disabled={off}
          onClick={() =>
            void run(async () => {
              const proposal = await api.autoBalanceTeams({ gameId: game.id });
              setDraft({
                ...Object.fromEntries(proposal.A.map((u) => [u, 'A' as const])),
                ...Object.fromEntries(proposal.B.map((u) => [u, 'B' as const])),
              });
              setMessage(`Proposal: average ${Math.round(proposal.averages.A)} vs ${Math.round(proposal.averages.B)}. Save to keep it.`);
            })
          }
        >
          Auto-balance
        </button>
        <button disabled={off || !dirty} onClick={() => void run(() => api.assignTeams({ gameId: game.id, assignments: diff }), 'Teams saved.')}>
          Save teams
        </button>
        {game.teamsPublishedAt === null ? (
          <button
            disabled={off || dirty || problem !== null}
            title={problem ?? (dirty ? 'Save first' : '')}
            onClick={() => void run(() => api.publishTeams({ gameId: game.id, publish: true }), 'Teams published — players have been told.')}
          >
            Publish
          </button>
        ) : (
          <button className="secondary" disabled={off} onClick={() => void run(() => api.publishTeams({ gameId: game.id, publish: false }), 'Teams hidden.')}>
            Unpublish
          </button>
        )}
        <button
          className="secondary"
          disabled={off}
          onClick={() => {
            if (window.confirm('Clear all team assignments?')) void run(() => api.clearTeams({ gameId: game.id }), 'Teams cleared.');
          }}
        >
          Clear
        </button>
      </div>
      {problem && !dirty && game.teamsPublishedAt === null && <p className="muted">{problem}</p>}
      {message && <p role="status">{message}</p>}
    </div>
  );
}
```
